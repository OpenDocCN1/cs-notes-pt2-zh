## 调试二分查找算法 🔍

上一节我们介绍了二分查找的实现。本节中我们来看看之前代码中的一个问题。

以下是一个简化的求平方根二分查找代码：

```python
x = 0.5
epsilon = 0.01
low = 0.0
high = x
ans = (high + low) / 2.0
while abs(ans**2 - x) >= epsilon:
    if ans**2 < x:
        low = ans
    else:
        high = ans
    ans = (high + low) / 2.0
print(ans)
```

运行此代码寻找0.5的平方根时，程序会陷入无限循环。为了找出问题，我们需要进行调试。

以下是调试程序的核心步骤：

1.  **使用打印语句**：在循环内部打印关键变量的值，观察其变化。
2.  **避免懒惰**：清晰地标记每个打印值，例如 `print(‘ans =‘, ans)`，而不是简单地 `print(ans, low, high)`。

通过打印，我们发现变量 `ans`、`low` 和 `high` 的值都固定在了0.5，不再变化。这是因为当 `x=0.5` 时，初始搜索区间 `[0, 0.5]` 并不包含其平方根（约为0.707）。算法在一个不包含答案的区间内搜索，因此无法找到正确结果。

![](img/8e95f14f856b2d9487461c8a387c5f22_3.png)

**解决方案**是确保搜索区间包含答案。一个简单的修复方法是让 `high` 的初始值为 `max(x, 1.0)`。这样，对于小于1的数，搜索区间将从 `[0, 1]` 开始。

```python
high = max(x, 1.0)
```

## 引入函数：分解与抽象 🧩

虽然我们修复了代码，但它仍不理想。每次计算不同数的平方根都需要修改源代码，并且无法在大型程序中方便地复用这段代码。编写更多代码通常意味着更高的出错概率。

![](img/8e95f14f856b2d9487461c8a387c5f22_5.png)

为了解决这个问题，我们引入**函数**。函数主要提供两种好处：**分解**和**抽象**。

![](img/8e95f14f856b2d9487461c8a387c5f22_7.png)

![](img/8e95f14f856b2d9487461c8a387c5f22_9.png)

*   **分解**：将程序拆分为独立的、可复用的**模块**（如函数）。这创造了结构。
*   **抽象**：将代码当作**黑盒**使用。使用者只需知道它**做什么**（通过规格说明），而无需知道它**如何做**（内部实现）。这允许我们轻松使用他人或自己编写的代码。

![](img/8e95f14f856b2d9487461c8a387c5f22_11.png)

函数让我们能够扩展语言，添加可以像内置操作符一样使用的新“原语”。

## 函数详解 ⚙️

![](img/8e95f14f856b2d9487461c8a387c5f22_17.png)

让我们通过一个例子来理解函数的组成部分。

![](img/8e95f14f856b2d9487461c8a387c5f22_19.png)

![](img/8e95f14f856b2d9487461c8a387c5f22_21.png)

![](img/8e95f14f856b2d9487461c8a387c5f22_23.png)

![](img/8e95f14f856b2d9487461c8a387c5f22_25.png)

```python
def withinEpsilon(x, y, epsilon):
    """
    参数 x, y, epsilon 均为浮点数，且 epsilon > 0。
    如果 x 在 y 的 epsilon 范围内，则返回 True，否则返回 False。
    """
    return abs(x - y) <= epsilon
```

![](img/8e95f14f856b2d9487461c8a387c5f22_27.png)

![](img/8e95f14f856b2d9487461c8a387c5f22_29.png)

1.  **定义关键字**：`def` 表示开始定义一个函数。
2.  **函数名**：`withinEpsilon`，应选择有意义的名称。
3.  **形式参数**：`x`, `y`, `epsilon`，是函数接收输入的变量。
4.  **函数体**：缩进的代码块，包含函数要执行的逻辑。
5.  **返回语句**：`return` 将计算结果返回给调用者。
6.  **文档字符串**：三引号内的文本，描述了函数的**规格说明**，这是实现抽象的关键。用户应通过阅读它来理解函数功能，而非直接阅读代码。

![](img/8e95f14f856b2d9487461c8a387c5f22_31.png)

![](img/8e95f14f856b2d9487461c8a387c5f22_33.png)

**调用函数**的方式如下：

![](img/8e95f14f856b2d9487461c8a387c5f22_35.png)

![](img/8e95f14f856b2d9487461c8a387c5f22_37.png)

```python
print(withinEpsilon(2, 3, 1)) # 输出：False
val = withinEpsilon(2, 3, 1.5) # val 的值为 True
```

**常见错误**：如果在函数中计算了值却忘记使用 `return` 语句，函数将返回特殊值 `None`。如果你在代码中意外看到 `None`，请检查是否遗漏了 `return`。

## 作用域与栈帧 🗺️

![](img/8e95f14f856b2d9487461c8a387c5f22_41.png)

理解函数调用时变量的作用域至关重要。关键概念是：**形式参数和函数内部定义的变量与函数外部的同名变量无关**。

![](img/8e95f14f856b2d9487461c8a387c5f22_43.png)

![](img/8e95f14f856b2d9487461c8a387c5f22_45.png)

![](img/8e95f14f856b2d9487461c8a387c5f22_47.png)


![](img/8e95f14f856b2d9487461c8a387c5f22_49.png)

```python
def f(x):
    x = x + 1
    print(‘x in f:‘, x)
    return x
x = 3
z = f(x)
print(‘z:‘, z)
print(‘x in main:‘, x)
```
输出结果为：
```
x in f: 4
z: 4
x in main: 3
```

![](img/8e95f14f856b2d9487461c8a387c5f22_51.png)

![](img/8e95f14f856b2d9487461c8a387c5f22_53.png)

![](img/8e95f14f856b2d9487461c8a387c5f22_55.png)

![](img/8e95f14f856b2d9487461c8a387c5f22_57.png)

**执行过程分析**：

![](img/8e95f14f856b2d9487461c8a387c5f22_59.png)

![](img/8e95f14f856b2d9487461c8a387c5f22_61.png)

1.  调用 `f(x)` 时，形式参数 `x` 被**绑定**到实际参数的值（整数3的对象）。
2.  进入函数 `f`，创建一个新的**作用域**（或**栈帧**）。作用域是一个从**名字**到**对象**的映射。
3.  在 `f` 的作用域中，`x` 首先指向整数3，然后执行 `x = x + 1`，使得 `f` 作用域中的 `x` 指向新的整数4。这完全不影响主作用域中的 `x`（仍指向3）。
4.  函数返回后，其作用域被销毁。

![](img/8e95f14f856b2d9487461c8a387c5f22_63.png)

当函数多层调用时，会形成一系列的栈帧，其创建和销毁遵循**后进先出**的原则，因此被称为“调用栈”。调试器中的“堆栈查看器”可以帮助我们查看每一层栈帧中的变量状态。

**断言 `assert`** 是一个有用的调试工具。`assert` 后跟一个表达式，如果表达式为 `True`，程序继续；如果为 `False`，程序立即停止并报错。它常用于“防御性编程”，在函数开始检查参数是否满足前提条件。

![](img/8e95f14f856b2d9487461c8a387c5f22_65.png)

```python
def findRoot(power, val, epsilon):
    """假设 power 是整数，val 和 epsilon 是正浮点数。
       返回一个浮点数 y，使得 y**power 在 val 的 epsilon 范围内。
       如果不存在这样的浮点数，则返回 None。"""
    assert power > 0 and isinstance(power, int), ‘power must be positive integer‘
    assert epsilon > 0, ‘epsilon must be positive‘
    # ... 函数其余部分 ...
```

## 字符串处理 📝

![](img/8e95f14f856b2d9487461c8a387c5f22_69.png)

到目前为止，我们主要处理数字。字符串是我们接触的第一个**非标量**值，即可以被分解处理的值。

**遍历字符串**：`for` 循环可以遍历任何可枚举其元素的类型，如字符串。

```python
total = 0
for c in str(1952): # 将数字转换为字符串 ‘1‘,‘9‘,‘5‘,‘2‘
    total += int(c) # 将字符转换回整数并相加
print(total) # 输出：17
```

![](img/8e95f14f856b2d9487461c8a387c5f22_71.png)

**索引与切片**：可以访问字符串的单个字符或子串。

```python
s = ‘ABC‘
print(s[0])   # 输出：‘A‘
print(s[0:1]) # 输出：‘A‘ (切片包含起始索引，不包含结束索引)
print(s[0:2]) # 输出：‘AB‘
```
切片操作会创建原字符串的一个**新副本**（子串）。

![](img/8e95f14f856b2d9487461c8a387c5f22_73.png)

**字符串方法**：Python提供了许多字符串操作方法。

```python
s = ‘ABC‘
print(s.find(‘B‘)) # 输出：1 (返回子串‘B‘的起始索引)
```

![](img/8e95f14f856b2d9487461c8a387c5f22_75.png)

建议查阅Python官方文档以了解所有可用的字符串方法。
