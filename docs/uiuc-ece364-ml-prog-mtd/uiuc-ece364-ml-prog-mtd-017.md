## 卷积神经网络的模块化组织

![](img/da35cb336ac343e25108423bf826146c_1.png)

![](img/da35cb336ac343e25108423bf826146c_3.png)

上一节我们介绍了卷积神经网络的基本结构。本节中我们来看看如何通过模块化来更清晰地组织网络层。

我们可以使用 `torch.nn.Sequential` 类将一系列层打包成一个顺序执行的模块。这在网络结构复杂时非常有用，尤其是在处理并行层时，能帮助我们更好地管理代码。

![](img/da35cb336ac343e25108423bf826146c_5.png)

![](img/da35cb336ac343e25108423bf826146c_7.png)

以下是使用 `Sequential` 定义卷积块的示例：
```python
import torch.nn as nn

![](img/da35cb336ac343e25108423bf826146c_9.png)

![](img/da35cb336ac343e25108423bf826146c_11.png)

block1 = nn.Sequential(
    nn.Conv2d(in_channels=3, out_channels=16, kernel_size=3, padding=1),
    nn.ReLU(),
    nn.Conv2d(in_channels=16, out_channels=16, kernel_size=3, padding=1),
    nn.ReLU(),
    nn.MaxPool2d(kernel_size=2, stride=2)
)
```
在定义前向传播函数时，可以直接调用这些模块，使代码更简洁。例如，如果想让两个 `block1` 并行处理输入，可以这样做：
```python
def forward(self, x):
    x1 = self.block1(x)
    x2 = self.block1(x)  # 另一个并行分支
    # 后续处理...
```
打印模型时，`Sequential` 模块会以块的形式清晰展示其内部结构。

## 全卷积网络与图像分割

![](img/da35cb336ac343e25108423bf826146c_13.png)

![](img/da35cb336ac343e25108423bf826146c_14.png)

我们之前讨论的卷积网络是“全卷积”的，即每一层的权重都完全连接到下一层。卷积网络的应用远不止于图像分类。

![](img/da35cb336ac343e25108423bf826146c_16.png)

一个重要的任务是**图像分割**，其目标是将图像中的每个像素划分到不同的类别（如道路、车辆、建筑物）。这与图像分类不同，分类是给整张图片一个标签，而分割是为每个像素分配一个标签。

![](img/da35cb336ac343e25108423bf826146c_18.png)

为了实现像素级分类，输入是 `N x N` 的图像，输出也必须是相同尺寸的 `N x N` 图像，只不过每个像素的值代表其类别。

为此，我们通常采用**编码器-解码器**结构：
*   **编码器**：由多个卷积层组成，用于从输入图像中提取和压缩特征。
*   **解码器**：接收编码器提取的特征，并通过上采样等操作，将其“解码”回原始图像尺寸，为每个像素生成类别标签。

![](img/da35cb336ac343e25108423bf826146c_20.png)

![](img/da35cb336ac343e25108423bf826146c_22.png)

这种结构也被称为**全卷积网络**，因为它不包含全连接层，所有操作都是卷积或上采样，从而保持了空间维度。

除了分割，卷积网络还可用于图像去噪、超分辨率、目标检测（输出物体的边界框）等任务。

## 提升模型泛化能力

![](img/da35cb336ac343e25108423bf826146c_31.png)

![](img/da35cb336ac343e25108423bf826146c_32.png)

![](img/da35cb336ac343e25108423bf826146c_34.png)

构建一个好的机器学习模型，很大程度上依赖于高质量的数据集。如果数据集较小或质量不高，模型容易**过拟合**，即只在训练数据上表现好，而无法泛化到新数据。

以下是两种常用的防止过拟合、提升泛化能力的技术：

### 1. 数据增强

数据增强通过对训练图像进行一系列随机但合理的变换，来人工扩充数据集。这迫使模型学习更本质的特征，而不是记忆训练集中的特定细节。

以下是常见的图像增强操作：
*   **裁剪**：从不同位置裁剪图像。
*   **翻转**：水平或垂直翻转图像。
*   **色彩调整**：改变亮度、对比度、饱和度。
*   **模糊**：对图像应用轻微模糊。
*   **旋转**：对图像进行小幅旋转。

PyTorch 的 `torchvision.transforms` 模块提供了便捷的函数来实现这些变换。**关键建议**：在将增强后的数据输入模型前，务必检查生成的图像是否合理。

### 2. Dropout

Dropout 是一种在训练期间随机关闭（丢弃）网络中一部分神经元的技术。其思想是，如果模型有过拟合的倾向，说明其容量（神经元数量）可能超过了学习任务所需。

通过随机丢弃神经元，可以防止网络过于依赖某些特定的神经元或特征组合，从而鼓励网络学习更鲁棒、更通用的特征。在评估（测试）模型时，应使用所有神经元。

在 PyTorch 中，可以通过 `nn.Dropout` 层实现，并利用 `model.train()` 和 `model.eval()` 来切换训练和评估模式。

## 批标准化

在深度网络中，非线性激活函数的引入可能导致中间层输出的分布发生变化（如出现长尾分布），这不利于网络的稳定训练。

**批标准化** 通过对每一层的输入进行标准化处理，使其均值为0，方差为1，从而稳定分布。其公式为：
\[
\hat{x} = \frac{x - \mu}{\sqrt{\sigma^2 + \epsilon}}
\]
其中，\( \mu \) 是批数据的均值，\( \sigma \) 是标准差，\( \epsilon \) 是一个防止除零的小常数。通常还会引入可学习的参数 \( \gamma \)（缩放）和 \( \beta \)（平移）来增加网络的表达能力：
\[
y = \gamma \hat{x} + \beta
\]
批标准化通常能加速训练并提升模型性能。

## 卷积神经网络发展简史

卷积神经网络的发展与计算能力的提升密切相关：
*   **1998年 LeNet**：由 Yann LeCun 提出，成功应用于手写数字识别（MNIST数据集），是早期成功的CNN。
*   **2009年 ImageNet**：李飞飞等人创建的大规模图像数据集及年度竞赛，极大地推动了计算机视觉研究。
*   **2012年 AlexNet**：首次在大规模图像识别竞赛中成功应用GPU训练的深度CNN，取得了突破性成绩。
*   **VGGNet**：通过使用更小的卷积核和更深的网络结构，进一步提升了性能。
*   **ResNet**：引入了**残差连接**（跳跃连接），解决了极深网络中的梯度消失和“遗忘”问题，使得训练数百层的网络成为可能。

残差连接的思想启发了**注意力机制**，并自然地引向了下一主题：循环神经网络。

## 循环神经网络简介

之前讨论的网络都是**前馈网络**，它们没有记忆，一次性处理所有输入。但对于序列数据（如文本、语音、时间序列），其长度可变，且前后元素之间存在依赖关系。

**循环神经网络** 被设计用来处理这种序列数据。RNN 具有一个“隐藏状态”，可以看作是网络的记忆。在每一步，RNN 接收当前输入和上一步的隐藏状态，计算当前输出并更新隐藏状态。

最简单的RNN单元计算如下：
```python
import torch.nn as nn

class SimpleRNN(nn.Module):
    def __init__(self, input_size, hidden_size, output_size):
        super().__init__()
        self.hidden_size = hidden_size
        self.i2h = nn.Linear(input_size + hidden_size, hidden_size) # 输入到隐藏层
        self.i2o = nn.Linear(input_size + hidden_size, output_size) # 输入到输出层
        self.softmax = nn.LogSoftmax(dim=1)

    def forward(self, input, hidden):
        combined = torch.cat((input, hidden), 1)
        hidden = self.i2h(combined)
        output = self.i2o(combined)
        output = self.softmax(output)
        return output, hidden
```

### 处理文本数据：姓名分类示例

假设我们要根据人名判断其国籍。人名是字符序列。我们需要将字符转换为数值表示，常用方法是**独热编码**：一个向量长度等于字符表大小，仅在对应字符位置为1，其余为0。

训练时，我们将名字的每个字符依次输入RNN，最后一步的隐藏状态或输出包含了整个序列的信息，可用于分类（如通过一个全连接层得到国籍概率）。

PyTorch 提供了 `nn.RNN`、`nn.LSTM`、`nn.GRU` 等内置模块，简化了实现。

### RNN的变体与改进

*   **双向RNN**：同时运行一个前向RNN和一个后向RNN，然后合并它们的输出。这允许网络同时利用过去和未来的上下文信息，对于理解整个序列的含义很有帮助。
*   **堆叠RNN**：将多个RNN层堆叠起来，以增加模型的容量和表达能力。
*   **长短期记忆网络**：引入了“细胞状态”和“门控机制”（输入门、遗忘门、输出门），能更有效地学习长期依赖关系，缓解简单RNN的梯度消失/爆炸问题。
*   **门控循环单元**：LSTM的一种简化变体，合并了部分门控单元，通常能达到与LSTM相当的性能，但参数更少。

RNN及其变体可以处理多种序列任务，如机器翻译（多对多）、情感分析（多对一）、文本生成（一对多）等。
