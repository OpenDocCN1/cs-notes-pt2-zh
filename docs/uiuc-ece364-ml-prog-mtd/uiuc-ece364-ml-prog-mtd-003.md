## 概述与动机

上一节我们介绍了PyTorch张量和计算图的概念。本节中，我们来看看为什么线性代数对于机器学习至关重要。

在深度神经网络中，例如用于图像分类的AlexNet，模型包含数百万个相互连接的权重。训练的目标是调整这些权重，使模型的输出尽可能接近真实值（ground truth）。我们通过计算模型输出与真实值之间的差异（损失），然后利用梯度信息反向传播，逐层调整权重来实现这一目标。这个过程的核心是高效地处理高维数据（如图像像素）和权重矩阵，这正是线性代数发挥作用的地方。

## 重温计算图

为了理解PyTorch如何自动计算梯度，我们需要回顾计算图的概念。计算图将复杂的函数分解为一系列基本运算，并记录其依赖关系，使得反向传播求导变得系统化。

考虑一个复合函数：`y = sin(log(x^2 + 1))`。我们可以将其分解为三个基本函数：
*   `g(x) = x^2 + 1`
*   `h = log(g)`
*   `y = sin(h)`

根据链式法则，`y` 对 `x` 的导数可以计算为：
`dy/dx = (dy/dh) * (dh/dg) * (dg/dx)`

PyTorch的计算图正是自动构建并跟踪这样的运算链。当我们创建一个需要梯度的张量（如 `x = torch.tensor([1.0], requires_grad=True)`）并对其执行一系列运算时，PyTorch会在幕后为每个运算创建对应的“节点”。这些节点不仅执行前向计算，还包含了用于计算其导数的反向传播函数（如 `PowerBackward`, `LogBackward`, `SinBackward`）。

因此，当我们调用 `y.backward()` 时，PyTorch会沿着计算图反向遍历，应用每个节点的反向函数，最终将梯度累积到初始张量 `x` 上。这使得我们能够轻松优化包含数百万参数的复杂函数。

## 线性代数基础

理解了自动求导的机制后，我们现在需要掌握处理高维数据（即参数和输入）的工具。这就是线性代数。

### 标量、向量、矩阵与张量

*   **标量**：单个数字，例如 `5`。
*   **向量**：一维数字数组，例如 `[1, 2, 3]`。可以视为空间中的一个点或方向。
*   **矩阵**：二维数字数组，具有行和列，例如 `[[1, 2], [3, 4]]`。
*   **张量**：广义的`n`维数组。标量是0维张量，向量是1维张量，矩阵是2维张量。在深度学习中，我们经常处理3维（如RGB图像批次）、4维或更高维的张量。一个理解高维张量的好方法是：将3维张量视为多个2维矩阵的堆叠，将4维张量视为多个3维张量的堆叠。

### 基本运算

以下是线性代数中的核心运算及其在PyTorch中的实现。

#### 转置

矩阵的转置通过交换其行和列得到。如果矩阵 `A` 的形状是 `(m, n)`，那么其转置 `A^T` 的形状是 `(n, m)`。

在PyTorch中，有两种方式实现：
*   `A.T`：仅适用于2维矩阵。
*   `torch.transpose(A, dim0, dim1)`：可以指定任意两个维度进行交换，适用于任意维度的张量。

```python
import torch
A = torch.tensor([[1, 2, 3], [4, 5, 6]]) # 形状 (2, 3)
print(A.T) # 形状 (3, 2)
print(torch.transpose(A, 0, 1)) # 形状 (3, 2)
```

#### 点积

两个向量的点积结果是一个标量。计算方式为对应元素相乘后求和。

公式：`a · b = Σ (a_i * b_i)`

在PyTorch中，可以使用 `torch.dot()`。
```python
a = torch.tensor([1, 2, 3])
b = torch.tensor([4, 5, 6])
dot_product = torch.dot(a, b) # 输出：1*4 + 2*5 + 3*6 = 32
```
点积满足交换律：`a · b = b · a`。**注意**：进行点积的两个向量必须长度相同。

#### 矩阵-向量积

矩阵 `A` (形状 `m x n`) 与向量 `x` (长度 `n`) 的乘积得到一个长度为 `m` 的新向量。这可以看作是矩阵 `A` 的每一行与向量 `x` 进行点积。

在PyTorch中，有专门优化的函数 `torch.mv()`。
```python
A = torch.tensor([[1, 2, 3], [4, 5, 6]]) # (2, 3)
x = torch.tensor([1, 0, -1]) # (3,)
result = torch.mv(A, x) # 输出：形状 (2,)
# 计算：[1*1+2*0+3*(-1), 4*1+5*0+6*(-1)] = [-2, -2]
```
也可以使用更通用的 `torch.matmul()` 或 `@` 运算符：`result = A @ x`。但 `torch.mv()` 在特定情况下计算效率更高。

#### 哈达玛积

哈达玛积是矩阵（或同形张量）的**元素对应乘积**。它要求参与运算的两个张量形状完全相同，结果张量的形状也保持不变。

在PyTorch中，使用 `*` 运算符。
```python
A = torch.tensor([[1, 2], [3, 4]])
B = torch.tensor([[5, 6], [7, 8]])
hadamard = A * B # 输出：[[1*5, 2*6], [3*7, 4*8]] = [[5, 12], [21, 32]]
```
对于向量，`*` 运算符同样执行元素级乘法（结果仍是向量），这与点积（结果为标量）不同。

#### 矩阵乘法

矩阵乘法（点积）是深度学习中最常见的运算之一。矩阵 `A` (形状 `m x p`) 与矩阵 `B` (形状 `p x n`) 相乘，得到新矩阵 `C` (形状 `m x n`)。`C` 中第 `i` 行第 `j` 列的元素是 `A` 的第 `i` 行与 `B` 的第 `j` 列的点积。

公式：`C[i, j] = Σ_k (A[i, k] * B[k, j])`

在PyTorch中，主要使用以下方法：
*   `torch.mm()`：专门用于2维矩阵乘法。
*   `@` 运算符：与 `torch.mm()` 功能相同，语法更简洁。
*   `torch.matmul()`：通用接口，功能最强大。

```python
A = torch.tensor([[1, 2], [3, 4], [5, 6]]) # (3, 2)
B = torch.tensor([[7, 8, 9], [10, 11, 12]]) # (2, 3)
C1 = torch.mm(A, B) # 形状 (3, 3)
C2 = A @ B # 形状 (3, 3)
```
**重要**：矩阵乘法不满足交换律，即 `A @ B` 通常不等于 `B @ A`。进行乘法时，必须保证 `A` 的列数等于 `B` 的行数。

#### 通用矩阵乘法 `torch.matmul()`

`torch.matmul()` 是一个智能的通用接口，它能根据输入张量的维度自动选择最合适的乘法规则：

*   两个1维向量：计算点积，返回标量。
*   两个2维矩阵：计算标准矩阵乘法。
*   1维向量和2维矩阵：将向量维度前置以匹配矩阵，进行乘法。
*   高维张量（批处理）：执行批矩阵乘法。这是处理数据批次的关键。例如，一个形状为 `(b, m, p)` 的张量可以与一个形状为 `(b, p, n)` 的张量相乘，得到形状为 `(b, m, n)` 的张量。这相当于对批次中的每一对 `(m, p)` 和 `(p, n)` 矩阵独立进行矩阵乘法。

```python
# 批处理示例
batch_A = torch.randn(10, 3, 4) # 10个 (3x4) 的矩阵
batch_B = torch.randn(10, 4, 5) # 10个 (4x5) 的矩阵
batch_C = torch.matmul(batch_A, batch_B) # 结果形状: (10, 3, 5)
```
