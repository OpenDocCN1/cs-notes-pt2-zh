## 概述 📋

![](img/6d16c6cbcffd1d443899fb9310241f15_9.png)

原始优化指的是我们直接求解的、带有约束条件的最优化问题。本节课的核心是理解梯度下降这一迭代优化算法，并探讨其变体（如带有动量的梯度下降）以及如何自适应地选择步长，以更高效地找到函数的最小值。

## 原始优化与凸性 🔍

上一节我们介绍了优化问题的基本框架。本节中我们来看看原始优化的具体含义以及一个关键的函数性质：凸性。

![](img/6d16c6cbcffd1d443899fb9310241f15_11.png)

![](img/6d16c6cbcffd1d443899fb9310241f15_12.png)

![](img/6d16c6cbcffd1d443899fb9310241f15_14.png)

![](img/6d16c6cbcffd1d443899fb9310241f15_16.png)

原始优化本质上就是我们迄今为止一直在做的事情：我们有一个需要最小化（或最大化）的目标函数，并且可能受到一些等式或不等式约束。我们试图找到能使目标函数值最小（或最大）的输入参数。这与对偶优化形成对比，后者会以新的方式重新表述问题。

![](img/6d16c6cbcffd1d443899fb9310241f15_18.png)

![](img/6d16c6cbcffd1d443899fb9310241f15_20.png)

![](img/6d16c6cbcffd1d443899fb9310241f15_22.png)

![](img/6d16c6cbcffd1d443899fb9310241f15_24.png)

![](img/6d16c6cbcffd1d443899fb9310241f15_26.png)

在优化中，一个重要的函数性质是凸性。凸函数具有一个关键特性：其图上任意两点之间的线段都位于函数图像之上或之上。这意味着函数的形状是“碗状”的，不会出现多个“坑”。

凸性的数学定义如下：对于函数 `f: ℝⁿ → ℝ`，如果对于所有定义域内的点 `x` 和 `y`，以及所有 `λ ∈ [0, 1]`，都满足以下不等式，则该函数是凸函数：
`f(λx + (1-λ)y) ≤ λf(x) + (1-λ)f(y)`

凸性之所以重要，主要有两个原因：
1.  **全局最优性保证**：对于凸函数，任何局部最小值都保证是全局最小值。这意味着一旦你找到了一个最小值，你就找到了最好的那个，无需担心陷入局部最优。
2.  **高效算法**：存在许多专门针对凸优化问题的高效算法，如梯度下降、牛顿法等，使得求解变得相对容易。

由于我们将要处理的线性模型通常是凸的，这使得它们的优化过程更加直接和可靠。

## 迭代算法与梯度下降框架 ⚙️

![](img/6d16c6cbcffd1d443899fb9310241f15_34.png)

理解了优化目标和函数性质后，我们来看看如何找到最小值。我们引入的梯度下降算法属于更广泛的迭代算法范畴。

![](img/6d16c6cbcffd1d443899fb9310241f15_36.png)

迭代算法的基本框架如下：
1.  从一个对输入参数的初始猜测开始。
2.  在当前位置，选择一个下降方向和步长。
3.  根据方向和步长更新输入参数。
4.  重新评估目标函数和梯度。
5.  检查是否满足停止条件（例如梯度为零）。
6.  若不满足，则重复步骤2-5。

![](img/6d16c6cbcffd1d443899fb9310241f15_38.png)

![](img/6d16c6cbcffd1d443899fb9310241f15_40.png)

在这个框架中，有两个核心问题需要回答：
1.  **选择什么方向？**
2.  **选择多大的步长？**

![](img/6d16c6cbcffd1d443899fb9310241f15_42.png)

对于方向，一个自然的选择是沿着函数下降最快的方向，即梯度的反方向。这种将下降方向设置为梯度负值的方法，被称为**最速下降法**。

![](img/6d16c6cbcffd1d443899fb9310241f15_44.png)

![](img/6d16c6cbcffd1d443899fb9310241f15_45.png)

![](img/6d16c6cbcffd1d443899fb9310241f15_47.png)

![](img/6d16c6cbcffd1d443899fb9310241f15_49.png)

![](img/6d16c6cbcffd1d443899fb9310241f15_51.png)

![](img/6d16c6cbcffd1d443899fb9310241f15_53.png)

对于步长，最简单的方法是使用一个固定的常数。**梯度下降**算法就是最速下降法（方向为梯度）加上恒定步长。虽然简单易实现，但固定步长有其局限性，我们稍后会看到。

## 自适应步长与Armijo准则 🔄

![](img/6d16c6cbcffd1d443899fb9310241f15_55.png)

![](img/6d16c6cbcffd1d443899fb9310241f15_56.png)

![](img/6d16c6cbcffd1d443899fb9310241f15_58.png)

![](img/6d16c6cbcffd1d443899fb9310241f15_60.png)

上一节我们看到了固定步长梯度下降的局限性。本节中我们来看看如何通过自适应地调整步长来改进算法。

固定步长的主要问题是：如果步长太小，收敛速度会非常慢；如果步长太大，算法可能会在最小值附近振荡甚至发散。一个理想的解决方案是，在每一步都沿着下降方向寻找能最大程度降低函数值的“最优”步长，这被称为**最优线搜索**。然而，精确求解最优步长的计算成本可能很高。

![](img/6d16c6cbcffd1d443899fb9310241f15_62.png)

![](img/6d16c6cbcffd1d443899fb9310241f15_64.png)

因此，实践中更常用的是近似但高效的规则。其中最流行的一种是**Armijo准则**（或回溯线搜索）。其核心思想是：
*   从一个较大的初始步长开始。
*   只要满足一个特定的“充分下降”条件，就保持这个大步长。
*   一旦条件不满足，就将步长按一定比例（如减半）衰减，然后重新检查，直到条件满足为止。

![](img/6d16c6cbcffd1d443899fb9310241f15_66.png)

![](img/6d16c6cbcffd1d443899fb9310241f15_68.png)

Armijo准则的充分下降条件通常表示为：
`f(w - α∇f(w)) ≤ f(w) - c * α * ||∇f(w)||²`
其中 `α` 是步长，`c` 是一个小的正常数（如0.01）。这个条件确保了每一步的下降量是“足够”的。

![](img/6d16c6cbcffd1d443899fb9310241f15_70.png)

![](img/6d16c6cbcffd1d443899fb9310241f15_72.png)

![](img/6d16c6cbcffd1d443899fb9310241f15_73.png)

通过动态调整步长，Armijo准则能够在函数变化平缓时采用大步长快速前进，在接近复杂区域或可能 overshoot 时自动缩小步长，从而在稳定性和收敛速度之间取得更好的平衡。

![](img/6d16c6cbcffd1d443899fb9310241f15_75.png)

![](img/6d16c6cbcffd1d443899fb9310241f15_76.png)

![](img/6d16c6cbcffd1d443899fb9310241f15_77.png)

![](img/6d16c6cbcffd1d443899fb9310241f15_79.png)

![](img/6d16c6cbcffd1d443899fb9310241f15_81.png)

## 动量：加速收敛与减少振荡 🚀

![](img/6d16c6cbcffd1d443899fb9310241f15_84.png)

![](img/6d16c6cbcffd1d443899fb9310241f15_85.png)

![](img/6d16c6cbcffd1d443899fb9310241f15_87.png)

![](img/6d16c6cbcffd1d443899fb9310241f15_89.png)

![](img/6d16c6cbcffd1d443899fb9310241f15_91.png)

即使使用了自适应步长，标准梯度下降在处理某些问题（如条件数很高的椭圆等高线）时，仍可能表现出缓慢的锯齿状收敛路径。为了解决这个问题，我们可以引入**动量**。

![](img/6d16c6cbcffd1d443899fb9310241f15_93.png)

![](img/6d16c6cbcffd1d443899fb9310241f15_95.png)

![](img/6d16c6cbcffd1d443899fb9310241f15_97.png)

动量法的灵感来源于物理学。在标准梯度下降中，参数的更新完全由当前点的梯度决定，没有“惯性”。动量法通过引入一个速度变量 `v` 来累积过去的梯度信息，使更新方向不仅考虑当前梯度，也考虑之前的更新方向。

带有动量的梯度下降更新规则如下：
```
v_{k+1} = β * v_k - α * ∇f(w_k)
w_{k+1} = w_k + v_{k+1}
```
其中：
*   `β` 是动量系数（通常接近1，如0.9），控制历史信息保留多少。
*   `α` 是学习率（步长）。
*   `v_k` 是累积的速度。

![](img/6d16c6cbcffd1d443899fb9310241f15_99.png)

![](img/6d16c6cbcffd1d443899fb9310241f15_101.png)

动量的作用主要体现在两个方面：
1.  **加速收敛**：在梯度方向一致的区域，动量会不断累积，使更新速度越来越快。
2.  **抑制振荡**：在梯度方向频繁改变的区域（如狭窄的山谷），动量起到平滑作用，抵消掉一部分相反方向的梯度，从而减少来回振荡，使路径更直接地指向最小值。

![](img/6d16c6cbcffd1d443899fb9310241f15_103.png)

![](img/6d16c6cbcffd1d443899fb9310241f15_104.png)

![](img/6d16c6cbcffd1d443899fb9310241f15_106.png)

![](img/6d16c6cbcffd1d443899fb9310241f15_107.png)

![](img/6d16c6cbcffd1d443899fb9310241f15_109.png)

![](img/6d16c6cbcffd1d443899fb9310241f15_111.png)

![](img/6d16c6cbcffd1d443899fb9310241f15_113.png)

本质上，动量项为优化过程提供了记忆，通过指数加权平均的方式融合了历史梯度信息，使得更新更加平滑和高效。

![](img/6d16c6cbcffd1d443899fb9310241f15_114.png)

![](img/6d16c6cbcffd1d443899fb9310241f15_116.png)

*   我们首先明确了**原始优化**问题的定义，并认识了**凸函数**及其在保证全局最优和简化优化方面的价值。
*   接着，我们剖析了**梯度下降**作为**迭代算法**的通用框架，其核心在于选择**下降方向**和**步长**。

*   最后，我们探讨了**动量法**，它通过引入速度变量来累积历史梯度信息，有效加速了收敛并减少了优化路径中的振荡。
