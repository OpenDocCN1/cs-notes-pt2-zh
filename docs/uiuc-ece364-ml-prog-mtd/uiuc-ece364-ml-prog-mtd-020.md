# 020：深度学习与图像任务

在本节课中，我们将要学习深度学习中的批标准化技术，并探讨两个重要的计算机视觉任务：语义分割和物体检测。我们将了解这些任务的基本概念、常用模型架构以及评估方法。

## 批标准化：加速深度网络训练

上一节我们介绍了深度神经网络训练中的一些挑战。本节中，我们来看看一个名为“批标准化”的技术，它旨在解决训练过程中内部协变量偏移的问题。

训练深度神经网络的一个复杂之处在于，随着前一层参数的改变，每一层输入的分布在训练期间会发生变化。这种现象被称为“内部协变量偏移”。它会导致网络训练变得缓慢且不稳定，因为后续层需要不断适应变化的输入分布。

批标准化通过在每个小批量数据上对层输入进行归一化来解决这个问题。其核心思想是：在网络的每一层之后，插入一个标准化层，将输入数据转换为均值为0、方差为1的分布。

以下是批标准化操作的公式化描述：

对于一个包含 `m` 个样本的小批量数据 `B = {x_1, ..., x_m}`，批标准化层执行以下计算：

1.  计算小批量的均值：
    `μ_B = (1/m) * Σ_{i=1}^{m} x_i`

2.  计算小批量的方差：
    `σ_B² = (1/m) * Σ_{i=1}^{m} (x_i - μ_B)²`

3.  对数据进行归一化：
    `x̂_i = (x_i - μ_B) / √(σ_B² + ε)`，其中 `ε` 是一个很小的常数，用于数值稳定性。

4.  进行缩放和偏移（引入可学习的参数 `γ` 和 `β`）：
    `y_i = γ * x̂_i + β`

参数 `γ` 和 `β` 允许网络学习最佳的缩放和偏移，而不是强制数据必须具有零均值和单位方差。这使得模型在保持训练稳定性的同时，仍能保留必要的表达能力。

批标准化层在卷积神经网络中非常常见。例如，在经典的ResNet等模型中，你经常会看到卷积层后紧跟着批标准化层。虽然它不一定直接提升模型的最终精度上限，但它能显著加速训练收敛过程，使训练过程更加稳定，从而在实践中被广泛采用。

## 语义分割：识别图像中的每个像素

在了解了提升训练效率的技术后，我们转向具体的视觉任务。首先，我们来看看语义分割。

![](img/44099f4caa69444ab5798ecd41a207ef_6.png)

![](img/44099f4caa69444ab5798ecd41a207ef_8.png)

![](img/44099f4caa69444ab5798ecd41a207ef_10.png)

语义分割的目标是为图像中的每一个像素分配一个类别标签。例如，在一张街景图片中，算法需要区分出哪些像素属于汽车、行人、建筑物或天空。其输出是一张与输入图像尺寸相同的“分割图”，其中每个像素的颜色代表其所属的类别。

实现语义分割的经典模型架构是编码器-解码器网络。

![](img/44099f4caa69444ab5798ecd41a207ef_12.png)

![](img/44099f4caa69444ab5798ecd41a207ef_14.png)

以下是其工作原理的简要描述：

*   **编码器**：通常由一系列卷积层和池化层组成。它的作用类似于一个特征提取器，将高分辨率的输入图像逐步压缩，提取出高级的、抽象的特征表示。在这个过程中，图像的空间尺寸（高度和宽度）会减小，而通道数会增加。
*   **解码器**：通常由一系列转置卷积层（或上采样层）组成。它的作用是将编码器提取的紧凑特征图“解码”回原始图像尺寸。解码器逐步恢复空间细节，最终输出每个像素的类别概率。

![](img/44099f4caa69444ab5798ecd41a207ef_16.png)

然而，标准的编码器-解码器结构存在一个问题：在编码阶段，经过多次下采样后，许多精细的空间信息会丢失，这可能导致解码器无法精确地重建物体边界。

![](img/44099f4caa69444ab5798ecd41a207ef_18.png)

![](img/44099f4caa69444ab5798ecd41a207ef_20.png)

![](img/44099f4caa69444ab5798ecd41a207ef_22.png)

![](img/44099f4caa69444ab5798ecd41a207ef_23.png)

为了解决信息丢失的问题，研究人员提出了U-Net等改进架构。U-Net的核心创新在于引入了“跳跃连接”。

以下是跳跃连接的工作方式：

![](img/44099f4caa69444ab5798ecd41a207ef_25.png)

![](img/44099f4caa69444ab5798ecd41a207ef_27.png)

![](img/44099f4caa69444ab5798ecd41a207ef_29.png)

在编码器的某一层提取特征后，除了将其传递给下一层，还会将其“复制”到解码器中对应分辨率的层，并与解码器该层的特征进行拼接。这样，解码器在重建图像时，不仅能利用高层抽象特征，还能直接获取来自编码器的、包含更多细节的低层特征。这种结构有效地保留了空间信息，显著提升了分割精度，尤其是在物体边界处。

![](img/44099f4caa69444ab5798ecd41a207ef_31.png)

## 物体检测：定位并识别图像中的物体

![](img/44099f4caa69444ab5798ecd41a207ef_33.png)

语义分割关注像素级分类，而另一个关键任务是物体检测，它需要找出图像中所有感兴趣物体的位置并用边界框标出。

物体检测的输出通常包括每个边界框的坐标（如左上角和右下角的x, y值，或中心点坐标及宽高）以及该框内物体的类别标签。

![](img/44099f4caa69444ab5798ecd41a207ef_35.png)

现代物体检测模型（如YOLO, SSD）的一个常见思路是使用“锚框”。

![](img/44099f4caa69444ab5798ecd41a207ef_37.png)

![](img/44099f4caa69444ab5798ecd41a207ef_39.png)

![](img/44099f4caa69444ab5798ecd41a207ef_41.png)

以下是锚框的基本概念：

![](img/44099f4caa69444ab5798ecd41a207ef_43.png)

![](img/44099f4caa69444ab5798ecd41a207ef_45.png)

![](img/44099f4caa69444ab5798ecd41a207ef_47.png)

![](img/44099f4caa69444ab5798ecd41a207ef_49.png)

模型将输入图像划分成一个S x S的网格。每个网格单元负责预测以该单元为中心的若干个边界框。这些预先定义好的、具有不同尺度和长宽比的边界框模板，就称为锚框。对于每个锚框，模型需要预测两类信息：
1.  **类别概率**：该框内包含某类物体的置信度。
2.  **位置偏移**：相对于预设锚框的精细调整值（如中心点微调、宽度和高度的缩放）。

![](img/44099f4caa69444ab5798ecd41a207ef_51.png)

为了衡量预测框与真实框之间的匹配程度，我们使用“交并比”指标。

![](img/44099f4caa69444ab5798ecd41a207ef_53.png)

交并比的计算公式如下：
`IoU = (预测框 ∩ 真实框的面积) / (预测框 ∪ 真实框的面积)`

![](img/44099f4caa69444ab5798ecd41a207ef_55.png)

IoU的值在0到1之间。值越大，表示两个框的重叠程度越高，预测越准确。通常，我们会设定一个阈值（如0.5），只有当预测框与某个真实框的IoU超过该阈值时，才认为这是一个正确的检测。

![](img/44099f4caa69444ab5798ecd41a207ef_56.png)

![](img/44099f4caa69444ab5798ecd41a207ef_58.png)

在模型推理时，它会为每个锚框生成一个预测。这会导致大量重叠的、针对同一物体的预测框。

![](img/44099f4caa69444ab5798ecd41a207ef_60.png)

为了从这些冗余的预测中筛选出最佳结果，我们使用“非极大值抑制”算法。

![](img/44099f4caa69444ab5798ecd41a207ef_62.png)

![](img/44099f4caa69444ab5798ecd41a207ef_64.png)

![](img/44099f4caa69444ab5798ecd41a207ef_65.png)

以下是NMS的步骤：
1.  将所有预测框按置信度（类别概率）从高到低排序。
2.  选取置信度最高的框，将其加入最终输出列表。
3.  计算该框与剩余所有框的IoU。
4.  移除所有IoU超过一定阈值（如0.5）且类别相同的框（即抑制掉与当前最优框高度重叠的次优框）。
5.  从剩余的框中重复步骤2-4，直到没有框剩下。

![](img/44099f4caa69444ab5798ecd41a207ef_67.png)

![](img/44099f4caa69444ab5798ecd41a207ef_69.png)

经过NMS处理后，我们通常能得到一组数量合理、且代表图像中不同物体的边界框。

![](img/44099f4caa69444ab5798ecd41a207ef_71.png)

![](img/44099f4caa69444ab5798ecd41a207ef_73.png)

评估物体检测模型的性能比分类任务更复杂，因为我们既要考虑定位准确性（框画得准不准），也要考虑分类准确性（认不认识是什么）。

![](img/44099f4caa69444ab5798ecd41a207ef_75.png)

以下是两个核心评估指标：
*   **精确率**：模型预测出的所有边界框中，真正正确的框所占的比例。`精确率 = 正确预测数 / 总预测数`
*   **召回率**：图像中所有真实物体中，被模型正确检测出来的比例。`召回率 = 正确预测数 / 真实物体总数`

精确率和召回率通常相互制约：提高检测阈值（只输出高置信度预测）会提升精确率但降低召回率；降低阈值则相反。

为了综合衡量模型性能，我们使用“精度-召回率曲线”及其衍生指标“平均精度”。

具体评估过程如下：
1.  将模型在测试集上所有图片的所有预测框，按置信度从高到低排序。
2.  从排名第一的预测框开始，逐个判断其是否为正确检测（IoU > 阈值）。
3.  每加入一个新的预测框，就计算当前的精确率和召回率。
4.  以召回率为横轴，精确率为纵轴，绘制出精度-召回率曲线。
5.  计算该曲线下的面积，即得到“平均精度”。对于多类别检测，对所有类别的AP取平均，即得到“均值平均精度”（mAP）。mAP是物体检测领域最主流的评估指标。

## 总结与迁移学习

本节课中我们一起学习了深度学习和计算机视觉中的几个核心主题。

我们首先探讨了**批标准化**，这是一种通过归一化层输入来加速深度网络训练、稳定训练过程的有效技术。接着，我们深入研究了两个重要的图像任务：**语义分割**和**物体检测**。对于语义分割，我们了解了编码器-解码器架构以及U-Net中跳跃连接的重要性。对于物体检测，我们掌握了锚框、交并比、非极大值抑制等关键概念，并学习了如何使用精确率、召回率和mAP来评估检测模型。

最后，一个在实践中极其重要的概念是**迁移学习**。由于从头训练一个强大的视觉模型需要海量数据和计算资源，我们通常利用在大型数据集（如ImageNet）上预训练好的模型（如ResNet、VGG的编码器部分）作为特征提取器。然后，我们“冻结”这些预训练模型的权重，只在其后添加并训练针对特定任务（如我们自己的分割或检测任务）的新网络层。这种方法能让我们在有限的数据和算力下，依然获得出色的性能，也是完成相关项目的高效途径。
