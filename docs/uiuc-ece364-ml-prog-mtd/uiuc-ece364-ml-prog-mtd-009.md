## 多参数线性回归

![](img/29e8f9b37193c5470dc704d970de254b_13.png)

![](img/29e8f9b37193c5470dc704d970de254b_15.png)

上一节我们讨论了单参数线性回归，即只有一个斜率参数和一个偏置参数。本节中，我们来看看当有多个输入特征时，如何扩展线性回归模型。

![](img/29e8f9b37193c5470dc704d970de254b_17.png)

![](img/29e8f9b37193c5470dc704d970de254b_19.png)

![](img/29e8f9b37193c5470dc704d970de254b_21.png)

多参数线性回归的模型可以表示为：
\[
y = w_0 + w_1 x_1 + w_2 x_2 + ... + w_n x_n
\]
其中，\( w_0 \) 是偏置项，\( w_1, w_2, ..., w_n \) 是每个特征 \( x_1, x_2, ..., x_n \) 对应的权重。

![](img/29e8f9b37193c5470dc704d970de254b_23.png)

以下是使用梯度下降法拟合一个二维平面（两个特征）的示例代码核心部分：

![](img/29e8f9b37193c5470dc704d970de254b_25.png)

![](img/29e8f9b37193c5470dc704d970de254b_27.png)

![](img/29e8f9b37193c5470dc704d970de254b_29.png)

![](img/29e8f9b37193c5470dc704d970de254b_30.png)

![](img/29e8f9b37193c5470dc704d970de254b_32.png)

![](img/29e8f9b37193c5470dc704d970de254b_34.png)

```python
# 初始化参数
w1 = torch.randn(1, requires_grad=True)
w2 = torch.randn(1, requires_grad=True)
b = torch.randn(1, requires_grad=True)

![](img/29e8f9b37193c5470dc704d970de254b_36.png)

![](img/29e8f9b37193c5470dc704d970de254b_38.png)

![](img/29e8f9b37193c5470dc704d970de254b_40.png)

![](img/29e8f9b37193c5470dc704d970de254b_42.png)

# 预测值
y_pred = b + w1 * x1 + w2 * x2

# 计算均方误差损失
loss = ((y_true - y_pred) ** 2).mean()

![](img/29e8f9b37193c5470dc704d970de254b_44.png)

![](img/29e8f9b37193c5470dc704d970de254b_46.png)

# 反向传播并更新参数
loss.backward()
with torch.no_grad():
    w1 -= learning_rate * w1.grad
    w2 -= learning_rate * w2.grad
    b -= learning_rate * b.grad
    # 清零梯度
    w1.grad.zero_()
    w2.grad.zero_()
    b.grad.zero_()
```

与单参数回归类似，多参数回归也可以通过矩阵运算得到解析解，公式为：
\[
\mathbf{w} = (\mathbf{X}^T \mathbf{X})^{-1} \mathbf{X}^T \mathbf{y}
\]
其中，\( \mathbf{X} \) 是包含一列1（对应偏置）和所有特征列的数据矩阵。

## 线性模型的局限性

既然线性回归有解析解且易于实现，一个自然的问题是：为什么不用它解决所有问题？本节中，我们来看看线性模型在处理复杂或非线性数据时的局限性。

以加州房价数据集为例，其中包含收入、房龄、房间数等多个特征。通过可视化可以发现，只有少数特征（如收入）与房价呈近似线性关系，而其他特征（如经纬度）的关系则非常复杂，难以用直线描述。尝试用线性模型拟合所有特征时，梯度可能会变得异常巨大（如出现 `nan` 或 `inf`），导致模型无法收敛。这表明，现实世界的数据往往不是线性的。

## 多项式回归

当数据关系非线性时，我们可以使用多项式回归。其核心思想是通过特征映射，将原始特征 \( x \) 转换为高次项（如 \( x^2, x^3 \)），然后在这些新特征上应用线性回归。

多项式模型可以表示为：
\[
y = w_0 + w_1 x + w_2 x^2 + ... + w_n x^n
\]

以下是实现多项式回归的关键步骤代码：

```python
# 定义多项式阶数
order = 3

# 初始化权重（每个阶次一个权重，外加偏置）
weights = torch.randn(order + 1, requires_grad=True)

# 构建特征映射：计算 x 的各次幂
features = torch.stack([x ** i for i in range(order + 1)], dim=1)

# 预测值
y_pred = (features * weights).sum(dim=1)

# 计算损失并更新（可使用带动量的梯度下降以稳定训练）
loss = ((y_true - y_pred) ** 2).mean()
loss.backward()
# ... 更新权重
```

多项式回归同样可以写成矩阵形式 \( \mathbf{y} = \mathbf{X} \mathbf{w} \)，其中矩阵 \( \mathbf{X} \) 的每一列是 \( x \) 的一个幂次项。因此，其最优权重同样可以通过解析解公式求得。

需要注意的是，当多项式阶数过高时，模型会完美拟合所有训练数据点（包括噪声），这种现象称为过拟合。例如，对于 N 个数据点，一个 N-1 阶多项式可以完全穿过所有点，但这通常不是我们想要的、能泛化到新数据的模型。

## 正则化

![](img/29e8f9b37193c5470dc704d970de254b_48.png)

在拟合模型时，数据中的噪声或异常值可能导致某些参数变得异常大，从而扭曲模型。正则化的目的是防止这种情况，鼓励模型保持较小的权重。

![](img/29e8f9b37193c5470dc704d970de254b_50.png)

最常用的 L2 正则化（也称岭回归）在损失函数中增加了一个惩罚项：
\[
L_{\text{total}} = \frac{1}{N}\sum (y_i - \hat{y}_i)^2 + \lambda \sum_{j} w_j^2
\]
其中，\( \lambda \) 是控制正则化强度的超参数。

加入 L2 正则化后，线性回归的解析解变为：
\[
\mathbf{w} = (\mathbf{X}^T \mathbf{X} + \lambda \mathbf{I})^{-1} \mathbf{X}^T \mathbf{y}
\]
其中 \( \mathbf{I} \) 是单位矩阵。

通过调整 \( \lambda \)，我们可以控制模型对异常值的敏感度。\( \lambda = 0 \) 时，即为普通线性回归；增大 \( \lambda \) 会迫使权重变小，使模型更平滑，但过大则可能导致模型欠拟合（例如变成一条水平线）。
