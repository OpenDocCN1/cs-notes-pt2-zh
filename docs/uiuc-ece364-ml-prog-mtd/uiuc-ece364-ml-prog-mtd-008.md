# 008：线性回归

## 概述
在本节课中，我们将要学习线性回归。线性回归是一种用于预测连续数值的机器学习方法。我们将从基本概念开始，介绍如何用线性模型拟合数据，并探讨两种求解最优参数的方法：梯度下降法和解析解法。

## 线性回归的基本思想
假设我们有一些数据点，将它们绘制在图上后，我们希望找到一个模型来预测这些数据。这些数据点通常包含输入（X）和输出（Y）。我们的目标是创建一个模型，给定相同的输入，能够给出预测输出。

## 模型选择与参数
我们首先需要选择一个模型。由于本讲的主题是线性回归，我们选择线性模型。线性模型的形式是 **y = Wx + B**，其中 **W** 是权重（斜率），**B** 是偏置（截距）。我们的目标是找到最佳的 **W** 和 **B**，使模型能最好地拟合数据。

## 损失函数
为了衡量模型预测值与实际数据之间的差距，我们引入损失函数。这里我们使用平方误差损失函数。对于单个数据点，损失函数定义为：
**L = 1/2 * (y - t)^2**
其中，**y** 是预测值，**t** 是目标值（真实值）。我们加上 **1/2** 是为了后续梯度计算更简洁。对于整个数据集，总损失是所有数据点损失的总和。

## 参数空间与优化
损失函数的值取决于参数 **W** 和 **B**。我们可以将损失函数视为一个三维曲面，其中 **W** 和 **B** 是自变量，损失值是因变量。我们的目标是找到这个曲面上的最低点，即损失最小的地方。对于线性回归，损失函数是凸函数，这意味着它只有一个全局最小值。

## 梯度下降法
梯度下降法是一种迭代优化算法，用于寻找损失函数的最小值。其基本思想是：从随机初始化的参数开始，计算损失函数的梯度，然后沿着梯度的反方向更新参数，以减小损失。更新公式为：
**W_new = W_old - α * ∂L/∂W**
**B_new = B_old - α * ∂L/∂B**
其中，**α** 是学习率，控制每次更新的步长。

以下是使用梯度下降法求解线性回归的代码示例：
```python
# 初始化参数
W = torch.randn(1, requires_grad=True)
B = torch.randn(1, requires_grad=True)

# 定义学习率和迭代次数
learning_rate = 0.01
iterations = 5000

for i in range(iterations):
    # 前向传播：计算预测值
    y_pred = W * X + B
    
    # 计算损失
    loss = ((y_pred - Y) ** 2).mean()
    
    # 反向传播：计算梯度
    loss.backward()
    
    # 更新参数
    with torch.no_grad():
        W -= learning_rate * W.grad
        B -= learning_rate * B.grad
        
        # 清零梯度
        W.grad.zero_()
        B.grad.zero_()
```

## 解析解法
对于线性回归，我们还可以使用解析解法直接求出最优参数。通过将损失函数对参数求导并令导数为零，我们可以得到参数的闭式解。最优权重 **W** 可以通过以下公式计算：
**W = (X^T X)^{-1} X^T T**
其中，**X** 是输入数据矩阵（包含一列1以处理偏置），**T** 是目标值向量。

以下是使用解析解法求解线性回归的代码示例：
```python
# 添加一列1到X以处理偏置项
X_with_bias = torch.cat([X, torch.ones(X.shape[0], 1)], dim=1)

# 计算最优权重
W_optimal = torch.inverse(X_with_bias.T @ X_with_bias) @ X_with_bias.T @ Y
```

## 梯度下降法与解析解法的比较
梯度下降法的优点是适用于各种模型，包括非线性模型，且易于实现。然而，它需要选择合适的学习率和迭代次数，并可能收敛缓慢。解析解法的优点是能直接得到精确解，计算效率高，但只适用于线性模型等具有闭式解的情况。

## 总结
本节课我们一起学习了线性回归的基本概念。我们介绍了线性模型、损失函数以及两种求解最优参数的方法：梯度下降法和解析解法。梯度下降法是一种通用的优化算法，而解析解法则为线性回归提供了精确且高效的解决方案。理解这些方法为我们后续学习更复杂的机器学习模型奠定了基础。
