
### 34.4-1 缩减到 3-CNF 的步骤

缩减的第二步将每个子句 $\phi$ 转换为合取范式。通过评估其变量的所有可能赋值来为 $\phi$ 构造真值表。真值表的每一行由子句变量的一个可能赋值以及该赋值下子句的值组成。利用评估为 `0` 的真值表条目，构建一个等价于 $\neg \phi$ 的***析取范式***（或 ***DNF***）— 一个 AND 的 OR，然后否定这个公式，并使用命题逻辑的***德摩根定律***将其转换为 CNF 公式 $\bar{\phi}$。

| $\neg (a \land b)$ | = | $\neg a \lor \neg b$ |
| :--- | :--- | :--- |
| $\neg (a \lor b)$ | = | $\neg a \land \neg b$ |

对所有文字取补，将 `OR` 变为 `AND`，将 `AND` 变为 `OR`。

在我们的例子中，子句 $\phi$ 转换为 CNF 如下。$\phi$ 的真值表出现在图 34.12 中。等价于 $\neg \phi$ 的 DNF 公式是：

```
(y[1] ∧ y[2] ∧ x[2]) ∨ 
(y[1] ∧ ¬y[2] ∧ x[2]) ∨ 
(y[1] ∧ ¬y[2] ∧ ¬x[2]) ∨ 
(¬y[1] ∧ y[2] ∧ ¬x[2])
```

取反并应用德摩根定律得到 CNF 公式 $\bar{\phi}$，它等价于原始子句 $\phi$。

到目前为止，公式 $\phi'$ 的每个子句 $\phi$ 已转换为 CNF 公式 $\bar{\phi}$，因此 $\phi'$ 等价于由 $\bar{\phi}$ 构成的 CNF 公式 $\phi''$ 的合取。此外，$\phi''$ 的每个子句最多有三个文字。

#### 第三步：转换为 3-CNF

归约的第三步也进一步转换了公式，使得每个子句都有*正好*三个不同的文字。从 CNF 公式 $\phi''$ 的子句构造最终的 3-CNF 公式 $\phi'''$。这个公式还使用了两个辅助变量 `p` 和 `q`。对于 $\phi''$ 的每个子句 $C[i]$，在 $\phi'''$ 中包含以下子句：

+   如果 $C[i]$ 包含三个不同的文字，则将 $C[i]$ 简单地包含为 $\phi'''$ 的一个子句。
+   如果 $C[i]$ 包含正好两个不同的文字，即如果 $C[i]$ = $(l[1] \lor l[2])$，其中 $l[1]$ 和 $l[2]$ 是文字，则将 $(l[1] \lor l[2] \lor p) \land (l[1] \lor l[2] \lor \neg p)$ 包含为 $\phi'''$ 的子句。文字 `p` 和 $\neg p$ 仅满足 $\phi'''$ 的每个子句包含正好三个不同文字的语法要求。无论 `p` = `0` 还是 `p` = `1`，其中一个子句等价于 $l[1] \lor l[2]$，另一个求值为 `1`，这是 `AND` 的恒等式。
+   如果 $C[i]$ 只包含一个不同的文字 `l`，则将 $(l \lor p \lor q) \land (l \lor p \lor \neg q) \land (l \lor \neg p \lor q) \land (l \lor \neg p \lor \neg q)$ 包含为 $\phi'''$ 的子句。无论 `p` 和 `q` 的值如何，其中四个子句中的一个等价于 `l`，另外三个求值为 `1`。

通过检查每个步骤，我们可以看到 3-CNF 公式 $\phi'''$ 仅当 $\phi$ 可满足时才可满足。与从 `CIRCUIT-SAT` 到 `SAT` 的归约类似，第一步中从 $\phi$ 到 $\phi'$ 的构造保持了可满足性。第二步产生了一个与 $\phi'$ 代数上等价的 CNF 公式 $\phi''$。然后第三步产生了一个与 $\phi''$ 有效等价的 3-CNF 公式 $\phi'''$，因为对变量 `p` 和 `q` 的任何赋值都会产生一个与 $\phi''$ 代数上等价的公式。

我们还必须展示归约可以在多项式时间内计算。从 $\phi$ 构造 $\phi'$ 最多引入一个变量和一个子句，每个 $\phi$ 中的连接词。从 $\phi'$ 构造 $\phi''$ 最多为 $\phi'$ 的每个子句引入八个子句，因为 $\phi'$ 的每个子句最多包含三个变量，并且每个子句的真值表最多有 $2^3 = 8$ 行。从 $\phi''$ 构造 $\phi'''$ 最多为 $\phi''$ 的每个子句引入四个子句。因此，结果公式 $\phi'''$ 的大小与原始公式的长度成多项式关系。每个构造都可以在多项式时间内完成。

### 34.5.1 团问题

无向图 $G = (V, E)$ 中的***团***是顶点的子集 $V' \subseteq V$，其中每对顶点在 $E$ 中由边连接。换句话说，团是 $G$ 的完全子图。***大小***是团包含的顶点数。***团问题***是在图中找到最大大小的团的优化问题。相应的决策问题只是询问图中是否存在给定大小 `k` 的团。正式定义如下：

```
CLIQUE = {〈G, k〉 : G 是包含大小为 k 的团的图}
```

一个用于确定具有 $|V|$ 个顶点的图 $G = (V, E)$ 是否包含大小为 `k` 的团的天真算法列出了 $V$ 的所有 `k` 子集，并检查每个子集是否形成团。该算法的运行时间是 $O(|V|^k \cdot |E|)$，如果 `k` 是一个常数，则是多项式的。然而，一般情况下，`k` 可能接近 $|V|/2$，此时算法运行时间为超多项式。事实上，一个高效的团问题算法不太可能存在。

**定理 34.11**
团问题是 NP 完全的。

**证明**
首先，我们展示 `CLIQUE` $\in$ `NP`。对于给定的图 $G = (V, E)$，将团中的顶点集 $V' \subseteq V$ 用作 $G$ 的证书。为了在多项式时间内检查 $V'$ 是否是团，检查对于每对 $u, v \in V'$，边 $(u, v)$ 是否属于 $E$。

接下来我们证明 `3-CNF-SAT` $\le_P$ `CLIQUE`，这表明团问题是 NP 难的。你可能会惊讶于证明将一个 `3-CNF-SAT` 实例简化为一个团实例，因为表面上逻辑公式似乎与图没有太多关系。

缩减算法从一个 `3-CNF-SAT` 实例开始。设 $\phi = C[1] \land C[2] \land \dots \land C[k]$ 是一个包含 `k` 个子句的 3-CNF 布尔公式。对于 $r = 1, 2, \dots, k$，每个子句 $C[r]$ 包含三个不同的文字：$l_{r1}$，$l_{r2}$ 和 $l_{r3}$。我们将构造一个图 $G$，使得 $\phi$ 可满足当且仅当 $G$ 包含大小为 `k` 的团。

我们按照以下方式构造无向图 $G = (V, E)$。对于 $\phi$ 中的每个子句 $C[r]$，将一个三元组的顶点 $v_{r1}$、$v_{r2}$ 和 $v_{r3}$ 放入 $V$ 中。如果以下两个条件都成立，则将边 $(v_{ri}, v_{sj})$ 加入 $E$：

+   $v_{ri}$ 和 $v_{sj}$ 在不同的三元组中，即 $r \neq s$，且
+   它们对应的文字是***一致***的，即，$l_{ri}$ 不是 $l_{sj}$ 的否定。

我们可以在多项式时间内从 $\phi$ 构建这个图。作为这个构造的一个例子，如果：

```
ϕ = (x[1] ∨ ¬x[2] ∨ ¬x[3]) ∧ (¬x[1] ∨ x[2] ∨ x[3]) ∧ (x[1] ∨ x[2] ∨ x[3])
```

则 $G$ 是在图 34.14 中显示的图。

我们必须证明 $\phi$ 到 $G$ 的这种转换是一个简化。首先，假设 $\phi$ 有一个满足赋值。那么每个子句 $C[r]$ 至少包含一个被赋值为 `1` 的文字 $l_{ri}$，并且每个这样的文字对应一个顶点 $v_{ri}$。从每个子句中选择一个这样的“真”文字得到一个 `k` 个顶点的集合 $V'$。我们声称 $V'$ 是一个团。对于任意两个顶点 $v_{ri}, v_{sj}$，其中 $r \neq s$，通过给定的满足赋值，对应的文字 $l_{ri}$ 和 $l_{sj}$ 都映射到 `1`，因此这些文字不可能是互补的。因此，根据 $G$ 的构造，边 $(v_{ri}, v_{sj})$ 属于 $E$。

反之，假设 $G$ 包含大小为 `k` 的团 $V'$。$G$ 中没有边连接同一三元组中的顶点，因此 $V'$ 中恰好包含每个三元组中的一个顶点。如果 $v_{ri} \in V'$，则将 `1` 赋给对应的文字 $l_{ri}$。由于 $G$ 中没有连接不一致文字的边，没有文字及其补充都被赋值为 `1`。每个子句都被满足，因此 $\phi$ 被满足。（任何不对应团中顶点的变量可以任意设置。）

**图 34.14** 图 $G$ 源自 3-CNF 公式 $\phi = C[1] \land C[2] \land C[3]$，其中 $C[1] = (x[1] \lor \neg x[2] \lor \neg x[3])$，$C[2] = (\neg x[1] \lor x[2] \lor x[3])$，$C[3] = (x[1] \lor x[2] \lor x[3])$，在将 `3-CNF-SAT` 简化为团问题时。公式的一个满足赋值为 `x[2]` = `0`，`x[3]` = `1`，`x[1]` 设置为 `0` 或 `1`。这个赋值通过使用 $\neg x[2]$ 满足 $C[1]$，并且通过 `x[3]` 满足 $C[2]$ 和 $C[3]$，对应于具有蓝色顶点的团。

在图 34.14 的例子中，$\phi$ 的一个满足赋值为 `x[2]` = `0` 和 `x[3]` = `1`。大小为 `k` = `3` 的一个对应团包含了来自第一个子句的 $\neg x[2]$，来自第二个子句的 `x[3]`，和来自第三个子句的 `x[3]` 的顶点。因为该团不包含任何对应 `x[1]` 或 $\neg x[1]$ 的顶点，这个满足赋值可以将 `x[1]` 设置为 `0` 或 `1`。

定理 34.11 的证明将 `3-CNF-SAT` 的任意实例缩减为具有特定结构的团问题实例。你可能会认为我们只证明了在顶点被限制为出现在三元组中且同一三元组中的顶点之间没有边的图中，团问题是 NP 难的。事实上，我们只证明了在这种受限情况下团问题是 NP 难的，但这个证明足以表明团问题在一般图中也是 NP 难的。为什么？如果存在一个能在一般图上解决团问题的多项式时间算法，那么它也会在受限图上解决团问题。

相反的方法——将具有特殊结构的 `3-CNF-SAT` 实例缩减为一般的团实例——却不够。为什么？也许我们选择要缩减的 `3-CNF-SAT` 实例是“简单”的，因此我们并没有将一个 NP 难问题缩减为团问题。

此外，缩减使用了 `3-CNF-SAT` 的实例，但没有使用解决方案。如果多项式时间缩减依赖于知道公式 $\phi$ 是否可满足，那么我们就会犯错，因为我们不知道如何在多项式时间内判断 $\phi$ 是否可满足。

### 34.5.2 顶点覆盖问题

一个无向图 $G = (V, E)$ 的***顶点覆盖***是一个子集 $V' \subseteq V$，使得如果 $(u, v) \in E$，则 $u \in V'$ 或 $v \in V'$（或两者都是）。也就是说，每个顶点“覆盖”其关联的边，而图 $G$ 的顶点覆盖是一个覆盖所有边的顶点集。顶点覆盖的***大小***是其中顶点的数量。例如，图 34.15(b)中的图有大小为 `2` 的顶点覆盖 $\{w, z\}$。

***顶点覆盖问题*** 是在给定图中找到最小大小的顶点覆盖。对于这个优化问题，相应的决策问题询问一个图是否有给定大小 `k` 的顶点覆盖。作为一种语言，我们定义：

```
VERTEX-COVER = {〈G, k〉 : 图 G 有大小为 k 的顶点覆盖}
```

下面的定理表明这个问题是 NP 完全的。

**定理 34.12**
顶点覆盖问题是 NP 完全的。

**证明**
我们首先展示 `VERTEX-COVER` $\in$ `NP`。给定一个图 $G = (V, E)$ 和一个整数 `k`，证书是顶点覆盖 $V' \subseteq V$ 本身。验证算法确认 $|V'| = k$，然后检查每条边 $(u, v) \in E$，确保 $u \in V'$ 或 $v \in V'$。在多项式时间内验证证书是很容易的。

为了证明顶点覆盖问题是 NP 难的，我们从团问题进行缩减，展示 `CLIQUE` $\le_P$ `VERTEX-COVER`。这个缩减依赖于图的补图概念。给定一个无向图 $G = (V, E)$，我们将 $G$ 的***补图***定义为一个图 $\bar{G} = (V, \bar{E})$，其中 $\bar{E} = \{(u, v) : u, v \in V, u \neq v, \text{且 } (u, v) \notin E\}$。换句话说，$\bar{G}$ 是包含所有不在 $G$ 中的边的图。图 34.15 展示了一个图及其补图，并说明了从团到顶点覆盖的缩减。

缩减算法以团问题实例 $\langle G, k \rangle$ 作为输入，并在多项式时间内计算出补图 $\bar{G}$。缩减算法的输出是顶点覆盖问题实例 $\langle \bar{G}, |V| - k \rangle$。为了完成证明，我们展示这个转换确实是一个缩减：图 $G$ 包含大小为 `k` 的团当且仅当图 $\bar{G}$ 有大小为 $|V| - k$ 的顶点覆盖。

假设 $G$ 包含一个团 $V' \subseteq V$，其中 $|V'| = k$。我们声称 $V - V'$ 是 $\bar{G}$ 中的一个顶点覆盖。设 $(u, v)$ 是 $\bar{E}$ 中的任意一条边。那么，$(u, v) \notin E$，这意味着 `u` 或 `v` 至少有一个不属于 $V'$，因为 $V'$ 中的每对顶点都由 $E$ 中的一条边连接。换句话说，`u` 或 `v` 至少有一个属于 $V - V'$，这意味着边 $(u, v)$ 被 $V - V'$ 覆盖。由于 $(u, v)$ 是从 $\bar{E}$ 中任意选择的，所以 $\bar{E}$ 中的每条边都被 $V - V'$ 中的一个顶点覆盖。因此，大小为 $|V| - k$ 的集合 $V - V'$ 形成了 $\bar{G}$ 的一个顶点覆盖。

相反，假设 $\bar{G}$ 有一个顶点覆盖 $V' \subseteq V$，其中 $|V'| = |V| - k$。对于所有 $u, v \in V$，如果 $(u, v) \in \bar{E}$，那么 $u \in V'$ 或 $v \in V'$ 或两者都是。这个蕴含的逆否命题是，对于所有 $u, v \in V$，如果 $u \notin V'$ 且 $v \notin V'$，那么 $(u, v) \in E$。换句话说，$V - V'$ 是一个团，它的大小为 $|V| - |V'| = k$。

由于 `VERTEX-COVER` 是 NP 完全的，我们不指望找到一个找到最小大小顶点覆盖的多项式时间算法。然而，第 35.1 节提供了一个多项式时间的“近似算法”，它为顶点覆盖问题产生“近似”解。算法产生的顶点覆盖的大小至多是最小顶点覆盖大小的两倍。

因此，你不应该因为一个问题是 NP 完全的就放弃希望。你可能能够设计一个多项式时间的近似算法，获得接近最优解，尽管找到一个最优解是 NP 完全的。第三十五章提供了几种 NP 完全问题的近似算法。

### 34.5.3 哈密顿回路问题

现在我们回到第 34.2 节中定义的哈密顿回路问题。

**定理 34.13**
哈密顿回路问题是 NP 完全的。
