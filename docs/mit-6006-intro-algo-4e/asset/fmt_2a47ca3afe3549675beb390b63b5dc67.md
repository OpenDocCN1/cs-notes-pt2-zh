
# 23 全对最短路径

在本章中，我们转向在图中查找所有顶点对之间的最短路径的问题。这个问题的一个经典应用是计算道路地图上所有城市对之间的距离表。也许经典，但并不是查找所有顶点对之间最短路径的真正应用。毕竟，将道路地图建模为图形式，每个道路交叉口有一个顶点，道路连接交叉口的地方有一条边。地图上的城市间距离表可能包括 100 个城市的距离，但美国大约有 300,000 个信号控制的交叉口¹，还有更多无控制的交叉口。

全对最短路径的一个合法应用是确定网络的直径：所有最短路径中的最长路径。如果一个有向图模拟通信网络，边的权重表示消息在通信链路上传输所需的时间，那么直径给出了网络中消息可能的最长传输时间。

如同第二十二章中一样，输入是一个带权重的有向图$G = (V, E)$，具有将边映射到实值权重的权重函数$w : E \rightarrow \mathbb{R}$。现在的目标是找到对于每对顶点$u, v \in V$，从$u$到$v$的最短（最小权重）路径，其中路径的权重是其组成边的权重之和。对于全对问题，输出通常采用表格形式，其中$u$行和$v$列中的条目是从$u$到$v$的最短路径的权重。

你可以通过运行单源最短路径算法$|V|$次来解决全对最短路径问题，每次以一个顶点作为源。如果所有边的权重都是非负的，你可以使用`Dijkstra`算法。如果你用线性数组实现最小优先队列，运行时间为$O(V^3 + VE)$，即$O(V^3)$。二进制最小堆实现的最小优先队列的运行时间为$O(V(V + E) \lg V)$。如果$|E| = \Omega(V)$，运行时间变为$O(VE \lg V)$，在图稀疏时比$O(V^3)$更快。另外，你可以用斐波那契堆实现最小优先队列，运行时间为$O(V^2 \lg V + VE)$。

如果图中包含负权边，`Dijkstra`算法无法工作，但你可以从每个顶点运行较慢的`Bellman-Ford`算法一次。结果的运行时间为$O(V^2E)$，在稠密图中为$O(V^4)$。本章展示了如何保证更好的渐近运行时间。它还探讨了全对最短路径问题与矩阵乘法的关系。

与单源算法不同，假设图的邻接列表表示，本章大部分算法使用邻接矩阵表示图。（`Johnson`算法用于稀疏图，在第 23.3 节中使用邻接列表。）为方便起见，我们假设顶点编号为 1, 2, … , $|V|$，因此输入是一个$n \times n$矩阵$W = (w_{ij})$，表示$n$顶点有向图$G = (V, E)$的边权重，其中

图中可能包含负权边，但我们暂时假设输入图中不包含负权环。

本章介绍的全对最短路径算法的表格输出是一个$n \times n$矩阵。输出矩阵的$(i, j)$条目包含$\delta(i, j)$，即从顶点$i$到顶点$j$的最短路径权重，如第二十二章中所示。

解决全对最短路径问题的完整解决方案不仅包括最短路径权重，还包括一个前任矩阵 $\Pi = (\pi_{ij})$，其中如果 $i = j$ 或者从 $i$ 到 $j$ 没有路径，则 $\pi_{ij}$ 为 `NIL`，否则 $\pi_{ij}$ 是从 $i$ 到 $j$ 的某条最短路径上 $j$ 的前任。正如来自第二十二章的前任子图 $G[\pi]$ 是给定源顶点的最短路径树一样，$\Pi$ 矩阵的第 $i$ 行诱导的子图应该是以 $i$ 为根的最短路径树。对于每个顶点 $i \in V$，$i$ 的前任子图 $G_i$ 是 $i$ 的前任子图 $G[\pi_i] = (V[\pi_i], E[\pi_i])$，其中

$V[\pi_i] = \{j \in V : \pi_{ij} \neq \text{NIL}\} \cup \{i\},$
$E[\pi_i] = \{(\pi_{ij}, j) : j \in V[\pi_i] - \{i\}\}.$

如果 $G[\pi_i]$ 是最短路径树，则下一页的 `PRINT-ALL-PAIRS-SHORTEST-PATH`，这是来自第二十章的 `PRINT-PATH` 程序的修改版本，打印从顶点 $i$ 到顶点 $j$ 的最短路径。

为了突出本章中全对算法的基本特征，我们不会像在第二十二章中处理前任子图那样广泛地涵盖如何计算前任矩阵及其属性。一些练习涵盖了基础知识。

```
PRINT-ALL-PAIRS-SHORTEST-PATH(Π, i, j)
1     if i == j
2     then output i
3     else if π[i, j] == NIL
4     then output "no path from i to j"
5     else
6         PRINT-ALL-PAIRS-SHORTEST-PATH(Π, i, π[i, j])
7         output j
```

在继续之前，我们需要为邻接矩阵表示建立一些约定。首先，我们通常假设输入图 $G = (V, E)$ 有 $n$ 个顶点，即 $n = |V|$。其次，我们使用大写字母表示矩阵，如 $W$、$L$ 或 $D$，并用带下标的小写字母表示它们的各个元素，如 $w_{ij}$、$l_{ij}$ 或 $d_{ij}$。最后，一些矩阵具有带括号上标的形式，如 $L^{(k)}$ 或 $D^{(k)}$，表示迭代。

## 23.1 最短路径和矩阵乘法

本节介绍了一个动态规划算法，用于解决有向图 $G = (V, E)$ 上的全对最短路径问题。动态规划的每个主要循环调用类似于矩阵乘法的操作，使得算法看起来像是重复的矩阵乘法。我们将首先为全对最短路径问题开发一个 $\Theta(V^4)$ 时间复杂度的算法，然后将其运行时间改进为 $\Theta(V^3 \lg V)$。

在继续之前，让我们简要回顾一下第十四章中为开发动态规划算法给出的步骤：

1. 描述最优解的结构。
2. 递归地定义最优解的值。
3. 以自底向上的方式计算最优解的值。

我们将第四步——从计算信息构造最优解——留给练习。

### 最短路径的结构

让我们从描述最优解的结构开始。引理 22.1 告诉我们，最短路径的所有子路径都是最短路径。考虑从顶点 $i$ 到顶点 $j$ 的最短路径 $p$，假设 $p$ 包含最多 $r$ 条边。假设没有负权重环路，则 $r$ 是有限的。如果 $i = j$，那么 $p$ 的权重为 0 且没有边。如果顶点 $i$ 和 $j$ 不同，则将路径 $p$ 分解为 $p' \rightarrow w_{kj}$，其中路径 $p'$ 现在包含最多 $r - 1$ 条边。引理 22.1 表示 $p'$ 是从 $i$ 到 $k$ 的最短路径，因此 $\delta(i, j) = \delta(i, k) + w_{kj}$。

### 所有对最短路径问题的递归解

现在，设 $L^{(r)}_{ij}$ 为从顶点 $i$ 到顶点 $j$ 的任何包含最多 $r$ 条边的路径的最小权重。当 $r = 0$ 时，如果 $i = j$，则从 $i$ 到 $j$ 的最短路径没有边，得到

$L^{(0)}_{ij} = \begin{cases} 0 & \text{if } i = j \\ \infty & \text{if } i \neq j \end{cases}$

对于 $r \geq 1$，实现从 $i$ 到 $j$ 的最多包含 $r$ 条边的最小权重路径的一种方法是采用包含最多 $r - 1$ 条边的路径，因此 $L^{(r)}_{ij} = L^{(r-1)}_{ij}$。另一种方法是从 $i$ 到某个顶点 $k$ 的最多 $r - 1$ 条边的路径，然后再取边 $(k, j)$，因此 $L^{(r)}_{ij} = L^{(r-1)}_{ik} + w_{kj}$。因此，要检查从 $i$ 到 $j$ 的最多包含 $r$ 条边的路径，尝试所有可能的 $j$ 的前驱 $k$，给出递归定义

$L^{(r)}_{ij} = \min(L^{(r-1)}_{ij}, \min_{1 \leq k \leq n} (L^{(r-1)}_{ik} + w_{kj}))$

最后一个等式来自于观察 $w_{jj} = 0$ 对所有 $j$ 成立。

实际的最短路径权重 $\delta(i, j)$ 是多少？如果图中不包含负权重环路，则每当 $\delta(i, j) < \infty$ 时，从顶点 $i$ 到顶点 $j$ 的最短路径就是简单的。（从 $i$ 到 $j$ 的路径 $p$ 如果不简单，则包含一个环路。由于每个环路的权重是非负的，将路径中的所有环路移除后，留下的简单路径的权重不会超过 $p$ 的权重。）因为任何简单路径最多包含 $n - 1$ 条边，从顶点 $i$ 到顶点 $j$ 的路径如果超过 $n - 1$ 条边，则不可能比最短路径的权重更低。因此，实际的最短路径权重由以下给出

$\delta(i, j) = L^{(n-1)}_{ij}$

### 自底向上计算最短路径权重

以矩阵 $W = (w_{ij})$ 为输入，让我们看看如何计算一系列矩阵 $L^{(0)}, L^{(1)}, \dots, L^{(n-1)}$，其中 $L^{(r)}_{ij}$ 对于 $r = 0, 1, \dots, n-1$。初始矩阵是由方程(23.2)给出的 $L^{(0)}$。最终矩阵 $L^{(n-1)}$ 包含实际的最短路径权重。

该算法的核心是实现方程(23.3)的过程 `EXTEND-SHORTEST-PATHS`，用于所有 $i$ 和 $j$。四个输入是迄今为止计算的矩阵 $L^{(r-1)}$；边权重矩阵 $W$；将保存计算结果的输出矩阵 $L^{(r)}$，在调用该过程之前，其所有元素都初始化为 $\infty$；以及顶点数 $n$。上标 $r$ 和 $r-1$ 有助于使伪代码与方程(23.3)的对应关系明显，但它们在伪代码中并不起实际作用。该过程通过再增加一条边扩展迄今为止计算的最短路径，生成迄今为止计算的矩阵 $L^{(r)}$ 的最短路径权重。由于存在三个嵌套的 `for` 循环，其运行时间为 $\Theta(n^3)$。

```
EXTEND-SHORTEST-PATHS(L^(r-1), W, L^(r), n)
1     // Assume L^(r) elements are initialized to ∞.
2     for i = 1 to n
3         for j = 1 to n
4             for k = 1 to n
5                 L^(r)[i, j] = min(L^(r)[i, j], L^(r-1)[i, k] + W[k, j])
```

现在让我们了解这个计算与矩阵乘法的关系。考虑如何计算两个 $n \times n$ 矩阵 $A$ 和 $B$ 的矩阵积 $C = A \cdot B$。`MATRIX-MULTIPLY` 在第 81 页使用的直接方法使用三重嵌套循环来实现方程式 (4.1)，我们在此为方便起见重复一次：

$c_{ij} = \sum_{k=1}^{n} a_{ik} b_{kj}$

对于 $i, j = 1, 2, \dots, n$。现在进行替换

| $l^{(r-1)}$ | $\rightarrow$ | $a$, |
| :--- | :--- | :--- |
| $w$ | $\rightarrow$ | $b$, |
| $l^{(r)}$ | $\rightarrow$ | $c$, |
| $\min$ | $\rightarrow$ | $+$, |
| $+$ | $\rightarrow$ | $\cdot$ |

在方程式 (23.3) 中。您得到方程式 (23.5)！对 `EXTEND-SHORTEST-PATHS` 进行这些更改，并将 $\infty$（$\min$ 的单位元）替换为 0（$+$ 的单位元），得到了过程 `MATRIX-MULTIPLY`。我们可以看到过程 `EXTEND-SHORTEST-PATHS(L^(r-1), W, L^(r), n)` 使用这种不寻常的矩阵乘法定义计算矩阵“乘积” $L^{(r)} = L^{(r-1)} \cdot W$。²

因此，我们可以通过反复相乘矩阵来解决全对最短路径问题。每一步都使用 `EXTEND-SHORTEST-PATHS(L^(r-1), W, L^(r), n)` 来执行矩阵乘法，将迄今为止计算的最短路径权重延伸一个边。从矩阵 $L^{(0)}$ 开始，我们产生以下序列的 $n - 1$ 个矩阵，对应于 $W$ 的幂：

$L^{(1)} = L^{(0)} \cdot W = W^1,$
$L^{(2)} = L^{(1)} \cdot W = W^2,$
$L^{(3)} = L^{(2)} \cdot W = W^3,$
$\dots$
$L^{(n-1)} = L^{(n-2)} \cdot W = W^{(n-1)}.$

最后，矩阵 $L^{(n-1)} = W^{(n-1)}$ 包含最短路径权重。

下一页的 `SLOW-APSP` 过程在 $\Theta(n^4)$ 时间内计算这个序列。该过程将 $n \times n$ 矩阵 $W$ 和 $L^{(0)}$ 作为输入，以及 $n$。图 23.1 说明了其操作。伪代码使用两个 $n \times n$ 矩阵 $L$ 和 $M$ 来存储 $W$ 的幂，每次迭代计算 $M = L \cdot W$。第 2 行初始化 $L = L^{(0)}$。对于每次迭代 $r$，第 4 行初始化 $M = \infty$，其中在这种情况下，$\infty$ 是一个标量 $\infty$ 值的矩阵。第 $r$ 次迭代从不变式 $L = L^{(r-1)} = W^{(r-1)}$ 开始。第 6 行计算 $M = L \cdot W = L^{(r-1)} \cdot W = W^{(r-1)} \cdot W = W^r = L^{(r)}$，以便通过第 7 行恢复不变式，设置 $L = M$，以便下一次迭代。最后，返回最短路径权重的矩阵 $L = L^{(n-1)} = W^{(n-1)}$。第 2、4 和 7 行对 $n \times n$ 矩阵的赋值隐含地运行双重嵌套循环，每次赋值需要 $\Theta(n^2)$ 的时间。$n - 1$ 次 `EXTEND-SHORTEST-PATHS` 的调用，每次需要 $\Theta(n^3)$ 的时间，主导了计算，产生了总运行时间为 $\Theta(n^4)$。

![art](img/Art_P691.jpg)

**图 23.1** 一个有向图和由 `SLOW-APSP` 计算的矩阵序列 $L^{(r)}$。您可能想要验证 $L^{(5)}$，定义为 $L^{(4)} \cdot W$，是否等于 $L^{(4)}$，因此对于所有 $r \geq 4$，$L^{(r)} = L^{(4)}$。

```
SLOW-APSP(W, L^(0), n)
1     let L = (l_ij) and M = (m_ij) be new n × n matrices
2     L = L^(0)
3     for r = 1 to n - 1
4         M = ∞               // initialize M
5         // compute matrix "product" M = L · W.
6         EXTEND-SHORTEST-PATHS(L, W, M, n)
7         L = M
8     return L
```

### 改进运行时间

请记住，目标不是计算所有的 $L^{(r)}$ 矩阵：只有矩阵 $L^{(n-1)}$ 才重要。回想在没有负权重环路的情况下，方程(23.4)意味着对于所有整数 $r \geq n - 1$，$L^{(r)} = L^{(n-1)}$。正如传统矩阵乘法是可结合的，通过 `EXTEND-SHORTEST-PATHS` 过程定义的矩阵乘法也是可结合的（参见练习 23.1-4）。实际上，我们可以通过重复平方法只用 $\lceil \lg(n - 1) \rceil$ 次矩阵乘法计算 $L^{(n-1)}$：

$L^{(n-1)} = L^{(2^{\lceil \lg(n-1) \rceil})}$

由于 $2^{\lceil \lg(n - 1) \rceil} \geq n - 1$，最终的乘积为 $L^{(n-1)}$。

`FASTER-APSP` 过程实现了这一思想。它只需要 $n \times n$ 矩阵 $W$ 和大小 $n$ 作为输入。行 4-8 的 `while` 循环的每次迭代都以不变式 $L = W^r$ 开始，使用 `EXTEND-SHORTEST-PATHS` 对其进行平方，得到矩阵 $M = L^2 = (W^r)^2 = W^{2r}$。在每次迭代结束时，$r$ 的值加倍，下一次迭代的 $L$ 变为 $M$，恢复不变量。当 $r \geq n - 1$ 时退出循环，过程通过方程(23.4)返回 $L = W^r = L^{(r)} = L^{(n-1)}$。与 `SLOW-APSP` 一样，行 2、5 和 8 中对 $n \times n$ 矩阵的赋值隐含地运行双重嵌套循环，每次赋值需要 $\Theta(n^2)$ 时间。

```
FASTER-APSP(W, n)
1     let L and M be new n × n matrices
2     L = W
3     r = 1
4     while r < n - 1
5         M = ∞             // initialize M
6         EXTEND-SHORTEST-PATHS(L, L, M, n)   // compute M = L²
7         r = 2r
8         L = M             // prepare for next iteration
9     return L
```

因为每个 $\lceil \lg(n - 1) \rceil$ 次矩阵乘法需要 $\Theta(n^3)$ 时间，所以 `FASTER-APSP` 的运行时间为 $\Theta(n^3 \lg n)$。代码紧凑，不包含复杂的数据结构，因此 $\Theta$-符号中隐藏的常数很小。
