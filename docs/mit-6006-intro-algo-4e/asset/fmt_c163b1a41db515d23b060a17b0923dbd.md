
`WITNESS` 的这个伪代码通过首先计算值 `x[0] = a^u mod n`（第 2 行）来计算 `a^(n–1) mod n`，然后在第 3–6 行的 `for` 循环中重复平方结果 `t` 次。通过对 `i` 进行归纳，计算的值序列 `x[0]`、`x[1]`、…、`x[t]` 满足方程式 `x[i] = a^(2^i * u) (mod n)` 对于 `i = 0, 1, …, t`，因此特别地 `x[t] = a^(n–1) (mod n)`。然而，在第 4 行执行平方步骤后，如果第 5–6 行检测到刚刚发现了 1 的非平凡平方根，循环将提前终止。（我们将很快解释这些测试。）如果是这样，该过程将停止并返回 `TRUE`。如果计算的 `x[t] = a^(n–1) (mod n)` 的值不等于 1，就像 `PSEUDOPRIME` 过程在这种情况下返回 `COMPOSITE` 一样，第 7–8 行返回 `TRUE`。如果第 6 或第 8 行没有返回 `TRUE`，则第 9 行返回 `FALSE`。

以下引理证明了 `WITNESS` 的正确性。

### 引理 31.38

如果 `WITNESS(a, n)` 返回 `TRUE`，则可以使用 `a` 作为证人构建 `n` 是合数的证明。

**证明** 如果第 8 行的 `WITNESS` 返回 `TRUE`，那是因为第 7 行确定 `x[t] = a^(n–1) mod n ≠ 1`。然而，如果 `n` 是质数，费马定理（定理 31.31）表明对于所有 `gcd(a, n) = 1`，`a^(n–1) = 1 (mod n)`。由于 `gcd(x[t], n) = 1`，如果 `n` 是质数，费马定理也表明对于所有 `gcd(x[t], n) = 1`，`x[t]^(n–1) = 1 (mod n)`。因此，`n` 不能是质数，而方程 `a^(n–1) mod n ≠ 1` 证明了这一事实。

如果 `WITNESS` 从第 6 行返回 `TRUE`，则它发现 `x[i–1]` 是 1 的一个非平凡平方根，模 `n`，因为我们有 `x[i–1] ≠ ±1 (mod n)`，但是 `x[i–1]² = 1 (mod n)`。第 934 页的推论 31.35 表明，只有 `n` 是合数时，模 `n` 才可能存在 1 的一个非平凡平方根，因此证明 `x[i–1]` 是 1 的一个非平凡平方根，模 `n` 证明了 `n` 是合数。

▪

因此，如果调用 `WITNESS(a, n)` 返回 `TRUE`，则 `n` 肯定是合数，证明了 `n` 是合数的证据是 `WITNESS` 返回 `TRUE` 的原因（是从第 6 行返回还是从第 8 行返回？）。

让我们探讨 `WITNESS` 的行为作为序列 `X = 〈x[0], x[1], …, x[t]〉` 的函数的另一种观点。当我们分析 Miller-Rabin 素性测试的错误率时，我们将发现这种观点很有用。请注意，如果对于某个 `0 ≤ i < t`，`x[i] = 1`，`WITNESS` 可能不会计算序列的其余部分。然而，如果它这样做了，每个值 `x[i+1]`，`x[i+2]`，…，`x[t]` 将是 1，因此我们可以将序列 `X` 中的这些位置视为全是 1。有四种情况：

1. `X = 〈…, d〉`，其中 `d ≠ 1`：序列 `X` 不以 1 结尾。在第 8 行返回 `TRUE`，因为 `a` 是 `n` 的合数的证明（根据费马定理）。
2. `X = 〈1, 1, …, 1〉`：序列 `X` 全是 1。返回 `FALSE`，因为 `a` 不是 `n` 的合数的证明。
3. `X = 〈…, –1, 1, …, 1〉`：序列 `X` 以 1 结尾，最后一个非 1 等于 -1。返回 `FALSE`，因为 `a` 不是 `n` 的合数的证明。
4. `X = 〈…, d, 1, …, 1〉`，其中 `d ≠ ±1`：序列 `X` 以 1 结尾，但最后一个非 1 不是 -1。在第 6 行返回 `TRUE`：`a` 是 `n` 的合数的证明，因为 `d` 是 1 的一个非平凡平方根。

现在，让我们根据 `WITNESS` 过程的使用方式来检查基于 Miller-Rabin 素性测试。与以前一样，假设 `n` 是大于 2 的奇整数。

`MILLER-RABIN` 过程是对 `n` 是合数的证明的概率性搜索。主循环（从第 1 行开始）从 `1 < a < n - 1` 中选择最多 `s` 个随机值的 `a`，除了 1 和 `n - 1`（第 2 行）。如果选择的 `a` 是 `n` 的合数的证明，那么 `MILLER-RABIN` 在第 4 行返回 `COMPOSITE`。由于 `WITNESS` 的正确性，这样的结果总是正确的。如果 `MILLER-RABIN` 在 `s` 次尝试中找不到证人，则该过程假定找不到证人是因为不存在证人，因此假定 `n` 是素数。如果 `s` 足够大，这个结果很可能是正确的，但是过程在选择 `s` 个随机值的 `a` 时仍有微小的机会，因此即使过程未能找到证人，至少存在一个证人。

为了说明 `MILLER-RABIN` 的操作，让 `n` 为卡迈克尔数 561，使得 `n - 1 = 560 = 2⁴ · 35`，`t = 4`，`u = 35`。如果过程选择 `a = 7` 作为基数，在图 31.4（第 31.6 节）中 `b = 35` 的列显示 `WITNESS` 计算 `x[0] = a³⁵ = 241 (mod 561)`。由于 `MODULAR-EXPONENTIATION` 过程如何递归地作用于其参数 `b`，图 31.4 中的前四列代表 560 的因子 `2⁴`——560 的二进制表示中最右边的四个零——从右向左读取这四个零。因此，`WITNESS` 计算序列 `X = 〈241, 298, 166, 67, 1〉`。然后，在最后的平方步骤中，`WITNESS` 发现 `a²⁸⁰` 是 1 的一个非平凡平方根，因为 `a²⁸⁰ = 67 (mod n)`，而 `(a²⁸⁰)² = a⁵⁶⁰ = 1 (mod n)`。因此，`a = 7` 是 `n` 的合数的证明，`WITNESS(7, n)` 返回 `TRUE`，`MILLER-RABIN` 返回 `COMPOSITE`。

如果 `n` 是一个 `β` 位数，`MILLER-RABIN` 需要 `O(sβ)` 算术运算和 `O(sβ³)` 位运算，因为它需要的工作量渐近地不超过 `s` 模指数运算。

### 米勒-拉宾素性测试的错误率

如果 `MILLER-RABIN` 返回 `PRIME`，则它出错的几率非常小。然而，与 `PSEUDOPRIME` 不同，错误的几率不取决于 `n`：对于此过程没有坏输入。相反，它取决于 `s` 的大小和在选择基值 `a` 时的“运气”。此外，由于每个测试比简单检查方程式 (31.39) 更严格，我们可以根据一般原则预期对于随机选择的整数 `n`，错误率应该很小。以下定理提供了更精确的论证。

### 定理 31.39

如果 `n` 是一个奇合数，那么对于 `n` 的合数性的见证数量至少为 `n - 1)/2`。

**证明** 证明表明非见证的数量最多为 `n - 1)/2`，这意味着定理成立。

我们首先声称任何非见证必须是 `Z_n^*` 的成员。为什么？考虑任何非见证 `a`。它必须满足 `a^(n–1) = 1 (mod n)` 或者等价地，`a · a^(n−2) = 1 (mod n)`。因此方程 `ax = 1 (mod n)` 有一个解，即 `a^(n−2)`。根据第 924 页的推论 31.21，`gcd(a, n) | 1`，这进而意味着 `gcd(a, n) = 1`。因此，`a` 是 `Z_n^*` 的成员，所有非见证都属于 `Z_n^*`。

为了完成证明，我们展示所有非见证不仅包含在 `Z_n^*` 中，它们都包含在 `Z_n^*` 的一个真子群 `B` 中（回想一下，当 `B` 是 `Z_n^*` 的子群但 `B` 不等于 `Z_n^*` 时，`B` 是一个真子群）。根据第 921 页的推论 31.16，我们有 `|B|` 整除 `|Z_n^*|`。由于 `|Z_n^*| = n - 1`，我们得到 `|B| ≤ (n - 1)/2`。因此，如果所有非见证都包含在 `Z_n^*` 的一个真子群中，那么非见证的数量最多为 `n - 1)/2`，因此见证的数量至少为 `n - 1)/2`。

要找到 `Z_n^*` 的一个真子群 `B`，其中包含所有非见证，我们考虑两种情况。

**情况 1:** 存在一个 `a ∈ Z_n^*`，使得

```
a^(n–1) ≠ 1 (mod n).
```

换句话说，`n` 不是卡迈克尔数。正如前面提到的，卡迈克尔数极为罕见，情况 1 是更典型的情况（例如，当 `n` 被随机选择并被测试为素数时）。

让 `B = { x ∈ Z_n^* | x^(n–1) ≡ 1 (mod n) }`。集合 `B` 必须非空，因为 `1 ∈ B`。集合 `B` 在模 `n` 下乘法运算封闭，因此根据定理 31.14，`B` 是 `Z_n^*` 的一个子群。每个非见证都属于 `B`，因为非见证 `a` 满足 `a^(n–1) = 1 (mod n)`。由于 `B ≠ Z_n^*`，我们得知 `B` 是 `Z_n^*` 的一个真子群。

**情况 2:** 对于所有 `a ∈ Z_n^*`，

```
a^(n–1) ≡ 1 (mod n).
```

换句话说，`n` 是一个卡迈克尔数。在实践中，这种情况极为罕见。然而，与伪素性测试不同，米勒-拉宾测试可以有效地确定卡迈克尔数是合数，正如我们将要看到的。

在这种情况下，`n` 不能是素数幂。为了看到为什么，假设相反，`n = p^e`，其中 `p` 是一个素数且 `e > 1`。我们通过以下方式推导出矛盾。由于我们假设 `n` 是奇数，`p` 也必须是奇数。第 933 页的定理 31.32 暗示 `Z_n^*` 是一个循环群：它包含一个生成元 `g`，使得 `g^(φ(n)) = 1 (mod n)`。（`φ(n)` 的公式来自第 920 页的方程 (31.21)。）根据方程 (31.40)，我们有 `g^(n–1) = 1 (mod n)`。然后离散对数定理（第 933 页的定理 31.33，取 `y = 0`）意味着 `n – 1 = 0 (mod φ(n))`，或

```
(p – 1)p^(e−1) | p^e – 1.
```

对于 `e > 1`，这个陈述是一个矛盾，因为 `(p – 1)p^(e−1)` 能被素数 `p` 整除，但 `p^e – 1` 不能。因此 `n` 不是素数幂。

由于奇合数 `n` 不是素数幂，我们将其分解为乘积 `n[1]n[2]`，其中 `n[1]` 和 `n[2]` 是大于 1 的奇数，它们互质。（我们可以有几种分解 `n` 的方式，我们选择哪一种并不重要。例如，如果 `n = p₁ᵏ¹…pⱼᵏʲ`，那么我们可以选择 `n[1] = p₁ᵏ¹` 和 `n[2] = p₂ᵏ²…pⱼᵏʲ`。）

回想一下，`t` 和 `u` 满足 `n – 1 = 2^t * u`，其中 `t ≥ 1` 且 `u` 是奇数，并且对于输入 `a`，过程 `WITNESS` 计算序列

```
x[i] = a^(2^i * u) mod n, i = 0, …, t.
```

所有计算都是在模 `n` 下进行的。

让我们称一对整数 `(v, j)` 为 **可接受**，如果 `gcd(v, n) = 1`，且

```
v^(n–1) ≡ 1 (mod n) 且 v^(2^j * u) ≡ -1 (mod n).
```

可接受的对肯定存在，因为 `u` 是奇数。选择 `v = n – 1` 和 `j = 0`，并且让 `u = 2k + 1`，以便 `u` 是奇数。对这个数取模 `n` 得到 `(n – 1)^(2k+1) = (n – 1)^(2k) · (n – 1) = (–1)^(2k) · –1 = −1 (mod n)`。因此，`(n – 1, 0)` 是一个可接受的对。现在选择最大可能的 `j`，使得存在一个可接受的对 `(v, j)`，并固定 `v` 以便 `(v, j)` 是一个可接受的对。让

```
B = { w ∈ Z_n^* | w^(n–1) ≡ 1 (mod n) 且 w^(2^j * u) ≡ 1 (mod n) }.
```

由于 `B` 在模 `n` 下乘法封闭，它是 `Z_n^*` 的一个子群。根据第 921 页的定理 31.15，因此，`|B|` 能整除 `|Z_n^*|`。每个非见证必须是 `B` 的成员，因为非见证产生的序列 `X` 要么全为 1，要么在第 `j` 个位置之前包含一个 -1，由于 `j` 的极大性。（如果 `(a, j′)` 是可接受的，其中 `a` 是一个非见证，我们必须根据我们选择 `j` 的方式，有 `j′ ≤ j`。）

现在我们利用存在的 `v` 来证明存在一个 `w ∈ Z_n^* \ B`，因此 `B` 是 `Z_n^*` 的一个适当子群。由于 `gcd(v, n) = 1`，根据中国余数定理的推论 31.29，我们也有 `gcd(w, n) = 1`。根据推论 31.28，存在一个 `w` 同时满足方程

| `w` | `≡` | `v` | `(mod n[1])` |
| :--- | :--- | :--- | :--- |
| `w` | `≡` | `1` | `(mod n[2])` |

因此，

```
w^(n–1) ≡ v^(n–1) ≡ 1 (mod n[1]) 且 w^(n–1) ≡ 1^(n–1) ≡ 1 (mod n[2]),
```
这意味着 `w^(n–1) ≡ 1 (mod n)`。并且 `w^(2^j * u) ≡ v^(2^j * u) ≡ -1 (mod n[1])` 意味着 `w^(2^j * u) ≠ 1 (mod n)`。因此，我们得出结论 `w ∈ Z_n^* \ B`，因此 `w ∉ B`。

还需要证明 `w ∈ Z_n^*`。我们首先分别在模 `n[1]` 和模 `n[2]` 下进行工作。在模 `n[1]` 下工作，由于 `gcd(v, n[1]) = 1`，我们有 `gcd(v, n) = 1`。此外，我们有 `gcd(v, n[1]) = 1`，因为如果 `v` 与 `n` 没有任何公共因子，那么它肯定也与 `n[1]` 没有任何公共因子。由于 `w ≡ v (mod n[1])`，我们看到 `gcd(w, n[1]) = 1`。在模 `n[2]` 下工作，我们有 `w ≡ 1 (mod n[2])` 意味着 `gcd(w, n[2]) = 1`，根据练习 31.2-3。由于 `gcd(w, n[1]) = 1` 和 `gcd(w, n[2]) = 1`，第 908 页的定理 31.6 得出 `gcd(w, n[1]n[2]) = gcd(w, n) = 1`。也就是说，`w ∈ Z_n^*`。

因此，我们有 `Z_n^* \ B ≠ ∅`，并且我们可以得出结论，在情况 2 中 `B`，包括所有非见证者，是 `Z_n^*` 的一个适当子群，因此大小最多为 `n - 1)/2`。

无论哪种情况，对于 `n` 的合数性至少有 `n - 1)/2` 个见证者。

▪

### 定理 31.40

对于任意奇数 `n > 2` 和正整数 `s`，`MILLER-RABIN(n, s)` 出错的概率最多为 `2^(-s)`。

**证明** 根据定理 31.39，如果 `n` 是合数，那么 `MILLER-RABIN` 的第 1-4 行的 `for` 循环的每次执行都有至少 1/2 的概率发现 `n` 的合数性的见证者。`MILLER-RABIN` 只有在在主循环的 `s` 次迭代中每次都不幸错过发现 `n` 的合数性的见证者时才会出错。这样一连串错过的概率最多为 `2^(-s)`。

▪

如果 `n` 是素数，`MILLER-RABIN` 总是报告 `PRIME`，如果 `n` 是合数，`MILLER-RABIN` 报告 `PRIME` 的概率最多为 `2^(-s)`。

然而，当将 `MILLER-RABIN` 应用于大随机选择的整数 `n` 时，我们还需要考虑 `n` 是素数的先验概率，以便正确解释 `MILLER-RABIN` 的结果。假设我们固定一个比特长度 `β` 并随机选择一个长度为 `β` 位的整数 `n` 进行素性测试，使得 `β ≈ lg n ≈ 1.443 ln n`。让 `A` 表示 `n` 是素数的事件。根据素数定理（定理 31.37），`n` 是素数的概率约为

| `Pr{A}` | `≈` | `1 / ln n` |
| :--- | :--- | :--- |
| | `≈` | `1.443 / β` |

现在让 `B` 表示 `MILLER-RABIN` 返回 `PRIME` 的事件。我们有 `Pr{B | A} = 1`（或者等价地，`Pr{B | A} = 1`）和 `Pr{B | not A} ≤ 2^(-s)`（或者等价地，`Pr{not B | not A} ≥ 1 - 2^(-s)`）。

但是 `Pr{A | B}` 是多少，即给定 `MILLER-RABIN` 返回 `PRIME` 的情况下 `n` 是素数的概率？根据贝叶斯定理的另一种形式（第 1189 页的方程 (C.20)）和近似 `ln n ≈ 1/β`，我们有

```
Pr{A | B} = Pr{B | A} * Pr{A} / Pr{B} ≥ Pr{A} / Pr{A} + (1 - Pr{A}) * 2^(-s) ≈ 1 / (1 + (1 - Pr{A}) * 2^(-s) / Pr{A})
```

直到 `s` 超过 `lg(ln n - 1)`，这个概率不会超过 1/2。直觉上，需要这么多的初始试验仅仅是为了通过未能找到 `n` 的合数性的见证者来克服对 `n` 是合数的先验偏见。对于具有 `β = 1024` 位的数字，这种初始测试需要大约
